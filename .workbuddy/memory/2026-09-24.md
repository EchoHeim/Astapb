**★ 踩坑（高价值）**：clone-flow 的 B5 用 `import_csv.py` 建表，而 **CSV 不携带字段类型** —— 源表里所有 `select` / `date` 字段全被降级成 `text`（字段名、记录数都对，只有类型错）。后果：页面写入用 `{select:...}` / `{date:...}` 会失败，**"双向同步"名义上通了、实际是断的**。读不受影响，因为页面读数据用了兼容写法 `if(typeof v==='object'&&v.text!=null)return v.text`，text 和 select 都能取值。

**修法**：克隆后必须把源表 schema 与克隆表 schema 逐字段比对，用 `update_database_field.py` 还原类型（select 要带全 options，date 用 `{"format":"yyyy-mm-dd"}`），再跑 CRUD 往返验证。已固化为用户级 skill `library-datapage-clone`。

**结果**：5 张表与源表 1:1（字段名/类型/记录数全一致：6/4/2/14/8 条），CRUD 往返 ADD→GET→DEL 成功。
