## 你好.gif 返工（v1 被 lodge 否掉，说「奇怪」）

两处都是真 bug：
1. **手被揉成橡皮泥**：权重场直接用高斯模糊（σ=11）当权值，掌心里大部分点权重只有 0.3~0.8，不同位置转角不同 → 手指伸缩、掌心压扁，不像挥手像揉面。改为**手内钳到 1.0、只在手外 ~8px 过渡**（`clip(blur(8)/255*2.2, 0, 1)`），幅度 11°→9°；手整体绕腕刚性旋转。
2. **文字闪动是残的**：`earred` 规则 `(r≥215 & g<150 & b<150 & r-g>70)` 把橙色字芯（255,138,26）也当耳红排掉了（字橙 b=26 落在 b<150 内），所以两轮闪的都只是阴影和高光，字芯纹丝不动。加 `b>70` 区分耳红（b≈110）后，mask 从 7405px → 14728px。
3. **闪光配色**：白热闪在浅色底上等于文字消失（仍像故障）→ 改成**金色闪光**（目标 #FFD842、峰值 0.85、单帧高斯脉冲 σ=0.032，对准挥手极值 f05/f15）。
最终：20帧 / 240×240 / 462KB / 1.2s；`_src/build_sticker_hello.py` 已覆盖更新。
**教训：用颜色规则抠图层时，排除条件的颜色范围必须和目标色核对——"耳红"和"字橙"在 RGB 上只差 b 通道。**

## 去干饭表情包改透明底（GIF 抠白底踩坑）

- **⭐ 白底抠透明必须用 `colorkey`，不能用 `chromakey`**：chromakey 按**色度**判定，黑与白色度都是 0 → 实测把 86.8% 的黑色字幕像素一起抠没了（字幕整块消失，肉眼一看就是"字没了"）。换 `colorkey=white:0.10:0.0` 后黑字误删 **0%**。
- 可用命令（一次性出透明 GIF，无需 PNG 中转）：
  `ffmpeg -i in.mp4 -vf "fps=15,scale=360:-1:flags=lanczos,colorkey=white:0.10:0.0,format=rgba,split[a][b];[a]palettegen=stats_mode=diff:reserve_transparent=1[p];[b][p]paletteuse=dither=bayer:bayer_scale=5:alpha_threshold=128" out.gif`
- **验收必须看 alpha**：`if a<32` 才算背景。踩过的坑——统计"深色像素"时忘了加 alpha 条件，把已抠透明的黑像素（RGB 保留为 0,0,0）也算进去了，得出"字幕还在"的假结论。
- 验收三指标（脚本 `output/ganfan-stickers/_verify.py`）：① 角落 alpha=0；② 透明占比 ≈ 白底版近白占比（本次 65.3/69.8/63.5/67.3 vs 64.8/68.3/62.8/66.8，说明只掉背景）；③ 字幕带深色像素 ≈ 白底版/2（采样步长不同），保留率 98~100%。另加"内部空洞"检测（四邻 4px 全不透明即算洞），防止眼白高光被抠穿——最大 330px，可忽略。
- ffmpeg 参数：本机版本**无 `-vsync`**，用 `-fps_mode passthrough`。

## 去白边返工（lodge 深色底实测露馅）

第一版白边明显的根因：**先缩到 360 再抠色**——lanczos 缩放把白底混进边缘 1px，形成混合环。量化数据显示不透明侧贴边环带 44% 像素亮度>190（216 灰/192 灰/奶油色），深色聊天背景上一圈白晕。

**正解管线（`output/ganfan-stickers/_defringe.py`，可复用）**：
1. 原生 768px 抠白（`dmax=(255-arr).max(axis=2)<26`，等效 colorkey 0.10）；
2. cv2.connectedComponents 回填**封闭洞**（护住眼睛高光/白碗——碗靠自身灰影存活，纯白高光靠回填）；
3. **预乘 alpha 后 BOX 缩到 360**（关键步：混合边在缩放中落到 alpha<0.5，二值化时自然剔除）；
4. alpha≥140 二值化；两轮「紧贴透明 ∧ min(rgb)>195 → 删」；1px 环带去白污染 `p'=255-(255-p)*1.45`；
5. Pillow 出 GIF：采样 10 帧拼 montaged quantize(255 色) 全局调色板，透明像素置品红占位取其索引当 transparency，`disposal=2, duration=66, optimize=False`。

效果：1px 白边从 ~1054 → 62~175 像素（-90%+），字幕深色像素保留 100%。剩余少量是奶油色毛边（真实毛色，不是白底残留），不宜再杀。

**验收脚本坑**：贴边环带统计必须「不透明 ∧ 膨胀(透明)」，掩码方向写反会量到透明像素自己的调色板占位色（ffmpeg reserve_transparent 占位是绿色 (0,240,0)，PIL 转 RGBA 后透明像素 RGB 就是它）——第一次就栽在这，量出 0 白边的假阴性。
