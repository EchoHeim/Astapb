## 环境坑
本机 bash 的 coreutils 时有时无（历史出现过缺失，别当稳定依赖）；PowerShell 不回显 stdout 且把 UTF-8 按 GBK 解码
→ **文件操作与读输出一律走 node 写文件 + Read 工具**；命令行正则会被 shell 吃掉反斜杠，一律写成 `.mjs`。
`git config core.quotepath false`。无头 Chrome 截图见 skill `local-html-visual-verify`。
**本机无 `gh` CLI**，取仓库数据用 `curl -s https://api.github.com/...` 喂 node。
**拉 raw.githubusercontent.com 大文件必须用 PowerShell**：`curl` 会被沙箱 SIGTERM 拦（26-10-22 实测），
`Invoke-WebRequest -Uri ... -OutFile ... -UseBasicParsing -TimeoutSec 60` 一次就成；
WebFetch 能读小文件，大文件会 `[content truncated]`。
**核 GitHub 项目**：README 之外必须再拉 `docs/`、`LICENSE*`、release notes——标题里的数字经常只对子功能成立。
