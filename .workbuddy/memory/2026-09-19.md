   健康参考：打开率老号 ≥8% 新号 ≥15%、推荐占比 10–30%、分享率 ≥1.5%。
2. **定位收敛（推荐方案 A）**：主号做「程序员的 AI 日报 + 硬核技术干货」双栏目，

   理由：105 篇技术文是唯一难复制的护城河，表情包谁都能做。方案 B（拆号）不推荐。

### 工具：rename-assets.mjs 三阶段
```bash
node CodeKey/运营方案/tools/rename-assets.mjs                    # 干跑预览
node CodeKey/运营方案/tools/rename-assets.mjs --apply            # 去 uuid → 001.png，生成 map + 对照表.md
node CodeKey/运营方案/tools/rename-assets.mjs --apply --semantic # 填好语义名 → 001-摸鱼.png
```
实现要点：目标文件已存在则跳过绝不覆盖；**编号每套独立**（表情平台分套上架）；
散落根目录的 2 张图只报告不移动；`numericPrefix()` 用 `/^(\d{1,4})[-.]/` 判定，
所以 `2c607d37-…`、`06de1695qq5d7c-…` 这类 uuid 名不会被误判出序号从而排到纯数字前缀文件之前。
已干跑验证：63 个文件全部识别，三套各自 001 起编。
