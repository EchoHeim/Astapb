## 公众号「程序小猴」品牌尾图（1080×500）

参考《燕云十六声》尾图结构，做了一版新尾图，落盘
`CodeKey/02-样式素材/封面与版式模板/尾图_程序小猴_1080x500_20261023.jpg`（148 KB）。

**结构迁移的三条关键判断**
1. 能搬的是结构、不是皮肤。燕云的「水墨+金色书法」是它的世界观，程序小猴只能换成
   「深蓝黑 + 科技青 + 暖金 + 3D 工位」，否则不伦不类。
2. **燕云那张一个赞/在看/分享图标都没画**，全靠文字引导。旧的三连图把三个圆形图标画了一遍，
   等于在微信自带的按钮上方贴了张说明书 —— 新版砍掉，画面立刻干净。
3. 话术必须用本账号世界观的语言。「这位游侠骨骼精奇」→「下次报错，你还得回来翻这篇」。

**版式**：左资料卡（AI 生成不了，代码画）+ 右下左转化/右传播双出口，两端对称、中间留形象。
旧版 750×163「三连图」继续保留，两者定位不同（轻量动作条 vs 重形象页），已写进 `说明.md`。

**踩过的坑**
- **AI 出图自带 "AI生成 WORKBUDDY" 水印**（右下角）。矩形补丁会留硬边，强模糊后仍留浅色轮廓，
  最后用「邻近取样纯色 + blur 22 羽化遮罩」才彻底清掉，收口交给底部渐变压暗。
- **小猴形象一致性靠 image-to-image**：第一版纯文生图出来是"温柔微笑"，参考图是"粗眉上挑倔强脸"，
  IP 特征全丢。把参考图作 `image1` + 明确写「thick dark eyebrows angled up / confident smirk」
  才对齐。**只用文字描述永远抓不住表情**。
- **中文一律不能交给模型**。资料卡里「78篇原创内容」「视频号：小猴随心记」这种字，模型必糊，
  且改一个字要重画整张。正确切分：AI 只出场景底图 → 文字/卡片/引导语全部 Pillow 绘制。

**成品参数**：1080×500 / JPG q92 subsampling=0 / 148 KB；
底部大字 36px、小字 19px（1080→375pt 约 0.35 倍，大字 ≈12.6pt）。
生成脚本 `_src/footer/build_footer.py`，改文案常量区重跑即覆盖。

## 《唐诗三百首》全文库（推文素材）

落盘 `CodeKey/03-选题与成稿/推文素材/唐诗三百首/`：313 首 / 11 卷 / 75 位作者 / 19073 字（不含标点）。
`目录.md`（313 行表格）+ 11 个分卷 md + 合订本 + `唐诗三百首.json` + README + `_src/`（脚本与校验报告）。

**分卷口径（四藤吟社本，关键别再记错）**：五古 33 / 五乐府 7 / 七古 28 / 七乐府 14 / 五律 80 / 七律 53 /
**乐府 1（附七律后，仅《独不见》）** / 五绝 29 / **乐府 8（附五绝后）** / 七绝 51 / **乐府 9（附七绝后）**
= 313。原书有**三卷都叫「乐府」**，是"各体之后附本体乐府"的编排，不是重名。
五乐府只有 7 首（塞下曲×2、关山月、子夜吴歌·秋歌、长干行、烈女操、游子吟）——
诗库网那版收 11 首（多塞上曲、春夏冬歌、登幽州台歌），是宽口径，**不要拿来当标准**。

**做法与可复用的经验**：
1. **原文绝不默写**。313 首的多源时代异文如果凭记忆写，异文/作者归属/乐府分卷必错一片。
   路径 = 抓一份结构完整的全文页 → 解析 → 双源交叉校验。
2. **格律是最好的自动质检器**。五律 4行×10字、七律 4行×14字、五绝 2行×10字、七绝 2行×14字，
   261 首近体诗一把过筛，解析错位（吞标题、漏行、多吞尾栏）会立刻暴露。古体无定式，只能靠句子级查漏。
3. **双源比对要分三层看**：首句指纹（能不能对上）、总字数（有没有缺句）、小句集合（缺哪句）。
   字数相同而内容不同 = 异文（曾云/层云、莫复问/闻），可接受；字数差一截才是事故。
4. 抓到的问题：源站**漏了李商隐《蝉》的单字标题**（P 标签 id 有跳号，编辑误删）；
   **末首吞了页面推荐栏 318 行**；**6 首小序混在正文里**（>35 字且句号结尾即可识别）；
   **2 处标题占 2-3 行**（回溯法：末尾不以句末标点结尾的行归下一首标题）。
5. 另一源（诗库网 300.json）**用描述占位生僻字**（「讧肯感激徒□（"妍"右上一横改为"合"）婀」），
   字数虚高，属于源本身质量差，不能拿它当基准去改正字。

**已确认的选本细节**：组诗编号保留原组序号（感遇十二首·其一 / 其七 中间不连续是对的）；
王维两首《送别》（卷一「下马饮君酒」、卷八「山中相送罢」）；李商隐 6 首无题；《金缕衣》从源本作「无名氏」。
