## 一个坑：不要并行 Edit 同一文件

一次消息里对**同一个文件**发两个 Edit 会互相覆盖（后写者覆盖前写者的全部改动，前一次的修改静默丢失，两次都返回成功）。发现方式：改完做一次逐行 diff 校验。以后同一文件的多处修改要么串行、要么直接 Write 重写整份。
