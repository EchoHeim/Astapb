# 尚德机构

本知识库全部原始资料的**来源机构与版权方**。所有 149 份文件的目录结构（`基础课` / `春笋班` /
`强化课` / `模考` / `考前冲刺`）即该机构管理类联考课程的**教研体系布局**。

> [!WARNING] 版权提示

> **不应推送到公开仓库或对外发布**。详见 [[WIKI-SCHEMA]] 的版权边界说明。

## 课程体系（从目录结构读出）

来源资料的顶层目录即为课程阶段：

| 目录 | 定位 |
| --- | --- |
| `英语/基础课` | 精讲 1–12 + 词汇 + 词根词缀 + 语法体系 + 官方笔记 |
| `英语/春笋班`、`数学/春笋班` | 专题课（语法 11 讲 / 数学 6 讲） |
| `英语/强化课`、`数学/提升课` | 强化段讲义、能力提升、整体复盘 |
| `英语/模拟冲刺`、`1221-考前冲刺` | 冲刺段（密训资料 + 模拟自测卷 + 蒙猜技巧） |
| `模考` | 试题 / 答案分离的模考卷 |
| `笔试小册子` | 各科便携速查（公式总结、高频词汇、真题） |
| `22级考试大纲及解析` | 官方考纲及解析 ⚠️ **4 份均为扫描件** |
| `写作` | 中文写作课件、讲义、模板、热点素材 |
