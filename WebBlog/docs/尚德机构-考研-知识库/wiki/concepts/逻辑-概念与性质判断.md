# 逻辑-概念与性质判断

对应《密训资料》「第一章 概念」与「第二章 判断与推理」的前半部分。这是形式逻辑的地基：
**概念间的关系、性质判断的对当关系、换质换位、模态判断**，考法固定、必须零失误。

## 定义

### 一、概念

概念是**反映事物本质属性的思维形式**。

- **内涵** = 概念所反映的事物的本质属性。例：「商品是用来交换的劳动产品」中，「用来交换的劳动产品」是「商品」的内涵。
- **外延** = 概念所反映的事物对象的数量和范围。例：森林包括防护林、用材林、经济林、薪炭林、特殊用途林。

**概念的种类**
| 类别 | 判别 |
| --- | --- |
| 单独概念 | 书名、人名、地名（《老人与海》、三亚） |
| 普遍概念 | 两个及以上对象（歌手、书籍） |
| 集合概念 | 反映整体，如「森林」——不能说一棵树就是森林 |
| 非集合概念 | 反映一类事物的非整体性，如「书」「山」 |

**区分集合概念 vs 非集合概念（★★★，来源资料给三法）**
1. 在需判断的词语前加「每一个」，通顺 ⇒ 非集合概念，不通顺 ⇒ 集合概念
2. 语句形式为「A 是 B」时，在 B 后加「之一」，通顺 ⇒ 非集合概念，不通顺 ⇒ 集合概念
3. 判定词的属性是整体的 ⇒ 集合概念；是个体的 ⇒ 非集合概念

**典型逻辑错误**
- **集合体误用**：根据集合体具有/不具有某性质，不当地断定个体也如此。
  例：「以人为本，我是人，所以，以我为本。」
- **混淆/偷换概念（★★★）**：把不同概念当同一个概念用。
  例：丈夫说「家中已点灯了」，妻子说的是元宵**花灯**，丈夫理解成照明的灯。

**概念间五关系（★★★）**

| 关系 | 例子 | 特征 |
| --- | --- | --- |
| 同一关系 | 北京 = 中国首都 | 外延完全重合 |
| 种属关系 | 河北人 ⊂ 北方人 | 一个外延包含另一个 |
| 交叉关系 | 学生 与 党员 | 部分重合 |
| 矛盾关系 | 男人 / 女人 | 不重合且之和为全集 |
| 反对关系 | 白色 / 黑色 | 不重合但之和非全集（还有红绿黄…） |

> 矛盾 vs 反对的**唯一判别**：两个概念的外延加起来是否穷尽整个论域。穷尽为矛盾，不穷尽为反对。

### 二、判断

判断的两个特征：**有所断定**（既无肯定也无所否定则不是判断）+ **有真假**。
- 「一加一等于三」是判断（有肯定，可判假）
- 「外面下雨了吗？」不是判断（无肯定否定，无法判真假）

### 三、性质判断（★★★）

结构四要素：**主项、谓项、联项、量项**。

| 类型 | 逻辑形式 | 例 |
| --- | --- | --- |
| 单称肯定 | S 是 P | 中国是人口大国 |
| 单称否定 | S 不是 P | 中国不是发达国家 |
| 全称肯定 | 所有 S 是 P | 所有学生都是青年人 |
| 全称否定 | 所有 S 不是 P | 所有学生都不是老年人 |
| 特称肯定 | 有的 S 是 P | 有些学生是文科学生 |
| 特称否定 | 有的 S 不是 P | 有的学生不是党员 |

**对当关系之矛盾关系**（必考）：
- 所有 S 都是 P　⟷　有的 S 不是 P
- 所有 S 都不是 P　⟷　有的 S 是 P
- 这个 S 是 P　⟷　这个 S 不是 P

### 四、变形推理（★★★）

**换质**：改变前提的质（肯定↔否定），主项量项不变，谓项变为矛盾概念。
- 所有 S 是 P ⇒ 所有 S 不是非 P
- 所有 S 不是 P ⇒ 所有 S 是非 P
- 有的 S 是 P ⇒ 有的 S 不是非 P
- 有的 S 不是 P ⇒ 有的 S 是非 P

**换位**：不改变质，只改主谓位置。
- 所有 S 是 P ⇒ **有的 P 是 S**（全称肯定只能换位成特称！）
- 所有 S 不是 P ⇒ 所有 P 不是 S
- 有的 S 是 P ⇒ 有的 P 是 S
- **有的 S 不是 P ⇒ 不能换位**

> 这两条限制（全称肯定限量、特称否定不可换位）是本章最高频的失分点。

### 五、模态判断（★）

四种形式：必然 P、必然非 P、可能 P、可能非 P。
**矛盾关系（必背）**：
- 不必然 P = 可能非 P
- 不必然非 P = 可能 P
- 不可能 P = 必然非 P
- 不可能非 P = 必然 P

含「并非」「不」「都」的转换示例（来源资料给出 5 例）：
- 所有产品都不必然合格 ⇒ 所有产品可能不合格
- 所有产品不必然都合格 ⇒ 有的产品可能不合格
- 所有产品必然不都不合格 ⇒ 必然有的产品合格
- 不是所有产品都必然不合格 ⇒ 可能有的产品合格
- 并非有的产品必然合格 ⇒ 所有产品可能不合格

## 典型例题

来源资料给出的性质判断矛盾关系真题（珠宝盗窃案）：
甲乙丙丁四人各说一句，只有一人说真话。乙说「丁是罪犯」，丁说「我不是罪犯」——两句互为矛盾，
故真话必在乙丁之间，于是甲、丙都为假。甲说「我不是罪犯」为假 ⇒ **甲是罪犯**。答案 A。

**解题套路**：先找矛盾关系锁定真话范围，再把范围外的人全部判假。

## 易错点

- 集合概念与非集合概念的判别，来源资料强调三种方法要**结合使用**，单用一条容易误判。
- 全称肯定判断换位后**必须限量**成「有的 P 是 S」，直接换成「所有 P 是 S」是经典错误。
- 特称否定判断**不能换位**。
- 模态判断的否定转换中，量项（所有/有的）也要跟着变，只改「必然/可能」是错的。
