# 英语-阅读八大题型与完形填空

英语二（204）的客观题主体。来源《【2101密训资料】管理类联考英语课（全国）》把完形、阅读、七选五
三章拆得很细，**每一章都给出了「大纲要求 + 文章特点 + 命题点 + 真题例句」**——
这份资料的价值在于它用**历年真题原句**标出了每一种题型的标志词。

## 定义

### 一、完形填空（Chapter 1）

| 项 | 内容 |
| --- | --- |
| 分值 | **20 小题 × 0.5 分 = 10 分** |
| 形式 | 约 300 词文章中留 20 个空，4 选 1 |
| 目标 | 补全后意思通顺、前后连贯、结构完整 |

**文章三大特点**：① 中心明确，全文围绕一个话题论述；② 论证严谨，论点 + 论据；③ **首句不设空**，开门见山引出话题。

**常考词性**：形容词、副词、动词、名词、介词、连词。

**词汇辨析四类**：
| 类型 | 例（来源资料原题） |
| --- | --- |
| 形异义近 | inflating / expanding / increasing / extending；lodging / shelter / dwelling / house |
| 形近义异 | measurable / manageable / affordable / renewable；complex / comprehensive / complementary / compensating |
| 形近义近 | ability / capability / capacity / faculty |
| 形异义异 | hardens / weakens / tightens / relaxes；aggravate / generate / moderate / enhance |

**必备短语搭配**：conform to（顺应）、react to（对…有反应）、be rooted in（根植于）、
around the corner（即将发生）、be entitled to（有权做某事）、be immune to（不受影响的）、
ground in/on（打好…的基础）、be associated with（与…联系）。

**逻辑关系词表（★★★ 必背，来源资料全表）**

| 关系 | 对应表达 |
| --- | --- |
| 转折 | however; though; in fact; although; but; yet |
| 让步 | although; even; even if; while; despite |
| 因果 | because; due to; owing to; thanks to; on account of |
| 比较 | whereas; while |
| 递进 | indeed; above all |
| 举例 | for example; for instance; like; such as |
| 并列 | or; as well as; along with; and |
| 增补 | also; except (for); apart from; aside from; other than |
| 目的 | so; for fear of |
| 总结 | so far |
| 条件 | when; if |

**解题步骤**：第一步边读边做，解决简单题目（**重视各段首句**）；第二步再次通读，解决剩余题目。

**六大解题技巧（来源资料逐一配真题）**
1. **利用首段首句最大限度获取信息**（注意第一句后可能有转折）
2. **近义词复现原则** —— 同类考查同义替换，根据文章前后近义词替换选答案
3. **利用逻辑关系解题** —— 根据逻辑推理词推理
4. **利用论证关系解题** —— 论点与论据的支撑/反驳关系（如 instead of 引出的 `opposite`）
5. **利用常识解题**
6. **利用搭配知识解题**（固定搭配题）

### 二、阅读理解八大考点（Chapter 2）

| # | 考点 | 对应题型 |
| --- | --- | --- |
| 1 | 理解主旨要义 | 文章主旨题 |
| 2 | 理解文章中的具体细节 | 事实细节题 |
| 3 | 理解文中的性含义 | 词义推测题 |
| 4 | 进行有关的判断、推理 | 判断题 / 推理引申题 |
| 5 | 根据上下文推测生词的词义 | 词义推测题 |
| 6 | 理解文章的总体结构以及上下文之间的关系 | 篇章结构题 |
| 7 | 理解作者的意图、观点或态度 | 观点态度题 |
| 8 | 区分论点和论据 | 写作目的题 |

**八大题型的题干特征与命题点**（来源资料对每种题型都给了真题例句）：

| 题型 | 题干标志 | 命题点 |
| --- | --- | --- |
| 事实细节题 | 题干较长、明确指向某段、含定位词（人名/地名/书名/机构/时间/数字） | 段落主旨句（首句、转折句）、长难句、复杂逻辑关系（因果/目的/对比/转折） |
| 词义推测题 | the word/phrase/expression "XX" (Para. X) most probably means… / is closest in meaning to… | 上下文线索 |
| 判断题 | 无定位词，Which of the following is true…? | 列举并列事物或并列观点处、介绍同一事物不同特征处 |
| 推理引申题 | what can we learn about…, It can be learned/inferred from Para X, it is implied/indicated/suggested… | 逻辑关系较复杂的段落；有时在长难句处命题 |
| 写作目的题 | X is noted/mentioned/cited/quoted to show/illustrate… 或 X is an example of… | 举例、引用、数据、研究结论、对比、比喻等**论据出现处** |
| 观点态度题 | the author's attitude towards X is… / towards X, the author feels… | 评价性词汇、转折处 |
| 主旨大意题 | the best title, the subject, mainly about/discuss, main idea | 首末段、各段首句 |
| 篇章结构题 | the author examines/discusses/introduces/deals with… by/with… | 引出主题的方式 |

### 三、七选五（Chapter 3）

- **信息匹配题**：从 A–G 中为 41–45 段选最合适的小标题，有 **2 个多余选项**，10 分
- **小标题匹配**：考结构与标题选择

**应试策略（★★★）**
1. 快速提取句子主干：五大基本句型
2. 把握句间逻辑：正向（重复、递进、因果）；反向（对比、转折）
3. 梳理段内整体逻辑

**段落主旨句的五个特征**（来源资料原文）
1. 抽象精炼、**后有举例/引用/数据等论据支撑**的首句往往是主旨句
2. **转折之后**往往出现主旨句
3. 用于**提出建议**的句子往往是主旨句
4. **总结性、结论性**语句往往是主旨句
5. **设问句引出的回答**通常是段落主旨句

**段际逻辑六种关系**：并列、顺接、因果、例证、转折、总分。

**解题步骤**：a. 浏览选项划关键词 → b. 快速浏览各段内容寻找主旨句（或主题词） → c. 结合排除法匹配标题。

## 解题方法 / 适用场景

- 阅读题的通用逻辑：**先看题干定题型，再回原文定位命题句，最后用同义替换选答案**。
- 题目顺序通常与行文顺序一致，可用于定位。
- 时间分配上，完形 + 阅读 + 七选五构成英语二客观题主体，需与翻译、写作合并控制在 180 分钟内。

## 典型例题

来源资料用**历年真题原句**标注题型，例如：
- 词义推测：`What does the phrase "to be aligned" (Line 5, Para. 6) most probably mean?`（2019）
- 写作目的：`The crash of EgyptAir Flight 804 is mentioned to____.`（2017）
- 观点态度：`What is the author's attitude towards the proposal?`（2020）
- 主旨大意：`What would be the best title for the text?`（2010）
- 篇章结构：`In the opening paragraph, the author introduces his topic by____.`（2005）
- 完形逻辑：`...smelled one type of flower but not another, __9__ others are sensitive to the smells of both flowers.`（2005，答案 whereas）

## 易错点

- 完形第一步如果纠缠难题会拖垮全局，来源资料明确「先做简单题，再回头处理剩余」。
- 「首句不设空」意味着**首句是免费的信息源**，很多考生没有充分利用。
- 判断题常设在「并列列举」处，多个选项看似都对，需要逐一回原文核对。
- 写作目的题问的是**用这个例子说明什么**，不是例子本身的内容。
