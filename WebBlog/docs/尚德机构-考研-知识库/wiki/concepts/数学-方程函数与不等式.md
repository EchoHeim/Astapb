# 数学-方程函数与不等式

对应《密训资料》「第 3 章 方程、函数与不等式」。这一章是管综数学里**条件充分性判断**的主战场——
「根的分布」「二次函数系数与图像的关系」几乎每年都以条件充分性判断形式出现。

## 定义

### 一元二次方程
标准式 $ax^2+bx+c=0\ (a\ne0)$，求根公式
$$x_{1,2}=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\quad(\Delta=b^2-4ac\ge0)$$

**根的判别式**：$\Delta>0$ 两个不等实根；$\Delta=0$ 两个相等实根；$\Delta<0$ 无实根。

**韦达定理**（★核心）：
$$x_1+x_2=-\frac ba,\qquad x_1x_2=\frac ca$$
来源资料明确其用途：**不解出方程，直接求有关方程根的代数式的值**。

### 根的分布（考试重点）
来源资料给了两种抓手：

1. **用韦达定理**判断根的符号：
   - 两正根 ⇒ $\Delta\ge0$ 且 $x_1+x_2>0$ 且 $x_1x_2>0$
   - 两负根 ⇒ $\Delta\ge0$ 且 $x_1+x_2<0$ 且 $x_1x_2>0$
   - 一正一负根 ⇒ $x_1x_2<0$
2. **数形结合**（来源资料标注「常用」），按区间情形讨论：
   | 情形 | 需要用的条件 |
   | --- | --- |
   | 两根同属一个连续区间 | $\Delta\ge0$ + 对称轴在区间内 + 两端点函数值正负 |
   | 两根分属两个不连续区间 | 只需端点函数值正负 |
   | 两根在一点两侧 | 只需该点函数值正负 |
   | 两不等根都在某点同侧 | $\Delta>0$ + 该点函数值正负 + 对称轴在该点一侧 |

### 一次函数 $y=kx+b$ 的符号规律
来源资料给的记忆口诀：
- $k>0$ 必过一、三象限；$k<0$ 必过二、四象限
- $b>0$ 必过一、二象限；$b<0$ 必过三、四象限
- $k>0$ 时 $y$ 随 $x$ 增大而增大，$k<0$ 时减小

### 二次函数的三种表达式
一般式 $y=ax^2+bx+c$；顶点式 $y=a\left(x+\frac{b}{2a}\right)^2+\frac{4ac-b^2}{4a}$；交点式 $y=a(x-x_1)(x-x_2)$。

系数作用：
- $a$ 定开口方向
- 对称轴 $x=-\frac{b}{2a}$，**$a,b$ 同号 ⇒ 对称轴在 $y$ 轴左侧；异号 ⇒ 右侧；$b=0$ ⇒ 对称轴即 $y$ 轴**

### 不等式基本性质（★★★）
1. 同乘正数不变号、乘负数变号
2. 传递性：$a>b,\ b>c\Rightarrow a>c$
3. 同向皆正相乘性：$a>b>0,\ c>d>0\Rightarrow ac>bd$
4. 同向相加性：$a>b,\ c>d\Rightarrow a+c>b+d$
5. 皆正倒数性：$a>b>0\Rightarrow 0<\frac1a<\frac1b$
6. 皆正乘方性：$a>b>0\Rightarrow a^n>b^n>0$

### 一元二次不等式的图像解法
来源资料以「开口向上的抛物线 $ax^2+bx+c\ (a>0)$ 的三种位置」列表给出解集：

| | $\Delta>0$ | $\Delta=0$ | $\Delta<0$ |
| --- | --- | --- | --- |
| $f(x)=0$ 根 | $x_{1,2}=\frac{-b\pm\sqrt\Delta}{2a}$ | $x_{1,2}=-\frac{b}{2a}$ | 无实根 |
| $f(x)>0$ 解集 | $x<x_1$ 或 $x>x_2$ | $x\ne-\frac{b}{2a}$ | $x\in\mathbb{R}$ |
| $f(x)<0$ 解集 | $x_1<x<x_2$ | $\varnothing$ | $\varnothing$ |

> 若二次项系数 $a<0$，**先化为正值再求解集**；若带等号，只需在解集里补上两个根。

### 集合
区间表示、包含关系（子集/真子集/相等）。结论：**含 $n$ 个元素的有限集共有 $2^n$ 个子集**。

## 典型例题

来源资料在本章给出的三道真题样例：
1. （2014.10）已知二次函数 $f(x)=ax^2+bx+c$，判断能否确定 $a,b,c$ 的值。条件为「过点 (0,0) 和 (1,1)"与「与直线 $y=a+b$ 相切」——典型条件充分性判断。
2. 求一元二次函数最大值。
3. 已知 $k^2x^2-(2k+1)x+1=0$ 有两个相异实根，求 $k$ 的取值范围。**陷阱在 $k\ne0$**（$k^2$ 为二次项系数），选项设计正是围绕这个点。

## 易错点

- 二次项系数含参数时，**必须单独讨论系数是否为 0**（上例第 3 题的 $k\ne0$）。
- 韦达定理使用前提是 $\Delta\ge0$，不能只用 $x_1x_2$ 的符号判断。
- 不等式两边约去含参式子时，**未讨论其正负**是最常见的失分点。
