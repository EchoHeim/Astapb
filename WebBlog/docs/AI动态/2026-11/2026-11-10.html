1. Anthropic 发布 Fable 5.2：复杂编程测试登顶，30小时证明费马大定理

Anthropic 于11月9日正式发布 Claude Fable 5.2 和 Mythos 5.2，两款模型共享底层架构，但在安全策略上做了差异化——Fable 面向所有用户，Mythos 仅向通过审核的网安和生命科学机构开放。Fable 5.2 在复杂编程测试 FrontierCode 2.0 上从上一代的 32.4% 飙升至 49.1%，超过 GPT-6 Astra 的 42.8% 和 Gemini 4 Carbon 的 41.1%。输出速度较上代提升 30%，价格下调 20%（输入 $8/M Token，输出 $40/M Token）。最硬核的演示：模型在 30 小时内完成了费马大定理的 Lean 形式化证明，还展示了 1000 个 AI Agent 协作 8 天搭建出操作系统原型的能力。

💡 小猴点评：Fable 5.2 的编程能力跃升幅度很大，FrontierCode 2.0 考的不是写个函数，而是端到端的复杂工程任务——这对日常做大型代码库重构和系统迁移的开发者来说，意味着 AI Copilot 的能力天花板又抬高了一截。1000 个 Agent 协作的演示更值得关注，多 Agent 编排一直是工程难题，Anthropic 这次把规模推到了新量级。

2. 美团开源 LongCat-2.5：1.6万亿参数，为长程Agent任务而生

美团龙猫正式开源 LongCat-2.5，MIT 协议，总参数 1.6 万亿，每个 Token 激活约 480 亿参数，原生支持 100 万上下文。模型定位为面向长程智能体任务的原生多模态模型，在复杂代码库开发、完整项目构建、Visual Coding 等场景中端到端交付能力有明显提升。技术上亮点不少：视觉信号用多层级离散 Token 表示而非外挂模块，训练环境会断网清缓存防止模型"作弊"，推理采用 W4A4 量化方案，并针对国产算力做了深度适配——单卡显存不足 80GB 也能跑起来。

💡 小猴点评：MIT 协议意味着商用无门槛，这点对开发者社区很重要。100 万上下文 + 长程 Agent 任务的组合，直接对标 Claude Code 和 Codex 的使用场景。特别有意思的是训练时"断网清 git"的反作弊设计——说明团队在认真解决模型走捷径的问题，而不是只刷跑分。国产算力的适配也很务实，对于受限于硬件条件的团队来说是个实用选择。

3. 字节跳动发布 Seedream 5.5：100轮编辑像素级保持，原生透明素材生成

字节跳动 Seed 团队发布新一代图像创作模型 Seedream 5.5，核心升级在多轮编辑稳定性和透明素材生成。模型支持围绕同一作品进行最多 100 轮连续编辑，非编辑区域实现像素级保持，不会出现色彩偏移或画质衰减。新增原生 RGBA 透明素材生成能力，可直接输出带 Alpha 通道的图像。API 定价约 0.28 元/张（2K 方图编辑），不到上代 Seedream 5.0 Pro 的一半。豆包、即梦已同步接入。

💡 小猴点评：100 轮编辑不崩坏这个能力对设计师来说是真的实用——以前 AI 生图最大的痛点之一就是"改了这里那里就崩了"。原生 RGBA 支持也省去了后期抠图的麻烦，做 UI 组件、图标素材的工作流可以更短。API 价格打到 0.28 元，对于需要批量出图的电商和设计团队来说，成本已经很低了。

4. 苹果开源 HALO 人形机器人系统：千问模型本地运行，91%成功率

苹果研究团队在 arXiv 发表论文并开源代码，披露了人形机器人自主控制系统 HALO。系统采用三层分层架构，最上层的任务编排模块使用阿里巴巴 Qwen3.6-35B-A3B 模型，在机器人搭载的 Mac mini 上本地运行，无需联网。在 6 个未预先扫描的真实环境中进行了 360 次单项任务测试，平均成功率 91%；组合任务成功率 70%。机器人可完成钻桌底、坐沙发、推箱子等动作。论文同时指出系统在遮挡场景下表现不佳，下一步将加入触觉感知。

💡 小猴点评：苹果选择开源机器人系统代码不太常见，说明他们在这个方向上更倾向于学术验证而非短期商业化。91% 的零样本迁移成功率验证了"纯仿真训练 → 真实部署"这条路径的可行性，这对机器人开发者来说是个重要信号——你不一定需要昂贵的真机数据采集。不过 70% 的组合任务成功率和遮挡场景的问题也说明，单靠视觉感知做机器人控制还有明显瓶颈。

5. 北京人形发布通用全身控制模型：多机协作完成长程任务

北京人形机器人创新中心发布通用全身控制模型，多机器人以一镜到底方式完成了会议室整理长程作业——搬移座椅、捡拾杂物、搬运垃圾袋、下蹲拾取纸团，多机之间可分工接续。模型瞄准的核心痛点是仿真与真实物理世界之间的鸿沟：当前行业普遍在平地行走和高动态表演上已过关，但面对真实环境的负载扰动和非结构化地形时稳定性会大幅衰减。短期落地场景瞄准工业现场和特种高危作业。

💡 小猴点评：从"能走"到"能干活"是人形机器人的关键跨越。这个演示的价值在于多机协作 + 长程任务——不是单次抓取，而是连续完成一套复杂操作。仿真到真实世界的 Sim2Real 鸿沟一直是具身智能的核心工程难题，北京人形这次展示了在多机场景下的突破，但论文也坦承家庭场景还有距离。对做机器人开发的同行来说，全身控制的开源方案值得期待。

6. 姚期智 × 杨植麟联合论文：给9个大模型出了张"图灵考试卷"

图灵奖得主姚期智和月之暗面创始人杨植麟联合发表论文 TCSExam，首次为理论计算机科学设计了一套覆盖定理证明、求解器工程、数学构造和开放猜想的完整评测。9 个前沿大模型参加考试，GPT-6 Astra 在定理证明类"裸考"拿下 70% 成功率，Kimi K3.1 Pro 以 38.3% 居第二。有趣的是，AI 在构造类任务上出现了超越人类已知记录的表现——Kimi K3 造出了一个 124 顶点、630 条边的特殊图，超过了论文引用的 629 条边参考记录。但在开放猜想类中，30 个长期未解猜想仅 6 次被接受，且都是"查资料查到"而非独立推导。

💡 小猴点评：这篇论文最有价值的发现不是谁考了多少分，而是揭示了大模型的能力边界——给它"递小抄"（中间引理）后性能显著提升，说明模型不是不会推理，而是需要更好的引导框架。对做 AI 应用开发的人来说，这验证了 Chain-of-Thought 和 RAG 的工程直觉：与其指望模型一步到位，不如给它搭好"脚手架"。

7. 蚂蚁灵波具身大模型挑战赛：1855支队伍角逐，48小时真机黑客松

蚂蚁灵波首届具身大模型挑战赛决赛名单出炉，15 支战队从全球 1855 支队伍、3252 位选手中晋级。决赛将于 11 月 14-15 日在上海张江进行 48 小时线下真机黑客松，选手统一使用松灵 COBOT MAGIC 设备和 LingBot-VLA 2.0 开源预训练模型，完成从任务理解到真机部署的全流程。蚂蚁灵波开源模型在 GitHub 累计获超 3.3 万 Star。

💡 小猴点评：1855 支队伍的参赛规模说明具身智能的热度确实在起来。48 小时真机黑客松比纯刷 paper 的比赛更接近真实工程场景——模型调完还得跑在真机上，软硬件协同的坑一个都绕不过去。对关注具身智能方向的开发者来说，这类比赛的开源方案和数据集是不错的学习资源。
