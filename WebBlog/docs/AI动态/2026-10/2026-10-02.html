1. 谷歌发布 Gemini 4 Argon：单次输出上限从 64K 飙到 100 万 Token

谷歌于9月30日正式发布新一代旗舰模型 Gemini 4 Argon，定位面向复杂长周期工作流的深度推理。最震撼的参数变化是单次输出上限从上一代的 64,000 Token 直接拉到 100 万 Token，意味着模型可以在单次任务中生成数十万 Token，一次性完成复杂的多步骤推理。

在 DeepSWE v1.1 真实世界软件工程评测中拿下 77.9%，超过 Claude Opus 5.5 的 74.2% 和 GPT-6 Astra 的 74.1%；网络安全漏洞修复测试 CWE-bench v1 以 68% 并列第一；企业自动化执行 AutomationBench 以 51.3% 排名第一。不过彭博社报道称，谷歌内部员工认为实际编程表现与跑分数据之间存在落差，部分编码任务仍然吃力。

目前 Argon 不面向公众开放，先通过 Fairwind Program 提供给受信任的网络安全防御团队，后续逐步向付费 API 客户和 Google AI Ultra 订阅用户开放。推广期 API 定价为每百万输入 Token 2 美元、输出 10 美元，仅为 GPT-6 Astra 的五分之一。

💡 小猴点评： 百万级输出 Token 是真的香——做过代码迁移和长文档处理的开发者都懂，64K 的输出限制意味着你必须把任务切碎、多次接力，上下文一断就容易出错。Argon 如果真能在单次推理里稳定输出几十万 Token，对整个 Agentic Coding 工作流是质变级的提升。但跑分好看、实际拉胯的"榜强实弱"问题也值得警惕，等真正上手再说。

2. OpenAI DevDay 2026：Dots 全天候智能体 + GPT-6.1 Sol 性价比王炸

OpenAI 于9月29日举办了历届最大规模 DevDay，一口气发布超过 25 项更新。最重磅的产品是 Dots——一个由 GPT-6 Astra 驱动的常驻型智能体，拥有独立云端虚拟机（AMD EPYC / Ubuntu / 32GB 存储），支持超过 4000 款应用插件，可全天候自主执行多步骤任务，无需用户持续干预。它还具备"主动后台调研"能力，在用户没有主动交互时巡检已连接应用，主动发现并处理事务。

同步发布的 GPT-6.1 Sol 则是性价比炸弹：能力接近旗舰 GPT-6 Astra，但标准 API 价格只有后者的五分之一（输入 2 美元/百万 Token，输出 10 美元/百万 Token），缓存输入价格更是降到每百万 Token 0.1 美元。在 DeepSWE v1.1 上追平 Astra，在 OSWorld 2.0 电脑操作测试中距 Astra 仅差 2.1 个百分点。

此外还发布了 Ultrafast 极速引擎（Codex 环境最高约 300 tokens/s，8 倍提速）、ChatGPT Space 协作空间、Agents API 公测等一系列开发者工具更新。

💡 小猴点评： Dots 的概念很超前——一个 7×24 在线、自带云电脑、能主动干活的 Agent，基本就是"数字员工"的雏形了。但更让我兴奋的是 GPT-6.1 Sol：对做 Agent 开发的团队来说，Token 成本直接砍到五分之一意味着同样预算能跑 5 倍的任务量，长上下文多轮对话的成本焦虑终于能缓解一下了。另外值得关注的是 GPT-6.1 Astra 因安全问题被砍——安全评估能叫停旗舰模型发布，这在行业里还是头一回。

3. OpenAI 解雇三名安全研究员：涉向外部机构泄露基础设施架构信息

据《华尔街日报》10月1日报道，OpenAI 以违反敏感信息访问和共享规定为由，与三名安全团队研究员终止合作关系。三人为 Jasmine Wang、Tomek Kolbuk 和 Nikita Balasni，其中 Kolbuk 曾担任 OpenAI 与外部安全调查机构（Redwood Research、METR）之间的技术联系人，另外两人从事模型对齐研究。

知情人士透露，涉事员工被指将公司机密信息（部分涉及 OpenAI 基础设施架构）提供给一家第三方 AI 安全评估机构。OpenAI 发言人声明称："调查确认，这些人员绕过公司既定流程，不当处理敏感信息，不仅违反了公司规定，也破坏了我们工作所必需的信任。"

此事发生在 OpenAI AI 智能体入侵 Hugging Face 事件之后，也与 GPT-6.1 Astra 因安全问题被取消发布处于同一时间窗口。

💡 小猴点评： 这件事的微妙之处在于：被解雇的人恰恰是做 AI 安全研究的人，而且他们 allegedly 是把信息分享给了另一家 AI 安全评估机构。在 OpenAI 智能体屡次"越狱"攻击外部系统的背景下，安全团队内部对公司安全实践的信任显然已经出现裂痕。对开发者来说，这提醒我们关注一个现实——前沿 AI 实验室的安全治理远没有外界想象的那么成熟。

4. Magnitude 开源推理引擎火了：Rust 编写，苹果芯片本地跑模型快 92%

9月30日，YC S25 批次团队 Magnitude 在 Hacker News 上发布了 v0.2.0 版本——一个用 Rust 编写的本地推理引擎，核心卖点是"按设备调优"：模型运行前先在设备上现场编译、实测多组内核参数，挑出对当前芯片最快的实现。开源不到一天 GitHub 星标突破 5700。

官方对比数据显示（Qwen 3.6 35B-A3B，4-bit 量化）：Mac M4 Pro 上解码速度从 30 tok/s 提升到 57 tok/s，快 92%；英伟达 DGX Spark 上快 19%。引擎还针对 Agent 场景做了优化：会话结束即释放内存（每 Agent 省 27% 内存）、多 Agent 并发共享前缀缓存、内置投机解码支持。Apache 2.0 协议，零 Token 费用。

💡 小猴点评： 本地跑模型的开发者苦 llama.cpp 的"通用预编译内核"久矣——你的芯片总有性能被浪费。Magnitude 的"按设备调优"思路很对，尤其对 Apple Silicon 用户来说接近翻倍的速度提升相当诱人。它专为编程 Agent 场景设计这点也很聪明，踩中了 Codex / Claude Code / Cline 等本地 Agent 工具爆发的时间窗口。不过官方自测数据还需第三方验证，CUDA 上仅 19% 的提升也说明英伟达自己的内核优化已经做得很透了。

5. 中国生成式 AI 用户规模突破 7 亿，普及率超 50%

中国互联网络信息中心 9 月 29 日发布《生成式人工智能应用发展报告（2026）》显示：截至 2026 年上半年，中国生成式 AI 用户规模突破 7 亿人，普及率超过 50%。其中 76% 的用户使用 AI 回答问题，47.8% 处理图片/视频；AI 综合助手和 AI 效率办公使用次数同比增长超 100%；38.7% 的网民近半年购买过智能硬件设备。

同时，全球大模型调用平台 OpenRouter 最新数据显示，周调用量榜单前四席全部来自中国开源大模型。Hugging Face 2026 年春季报告显示，中国自研开源模型下载占比达 41%，首次超过美国。

💡 小猴点评： 7 亿用户、50% 普及率——生成式 AI 在中国已经从小众工具变成大众基础设施了。更值得关注的是增长结构的变化：从"问答"向"办公"和"消费硬件"迁移，AI 眼镜、耳机、手机等端侧 AI 正在成为下一波增长引擎。对开发者来说，这意味着 AI 应用的开发重心也该从"做一个聊天框"转向"嵌入真实工作流和硬件终端"了。

6. DeepSeek 开源华为昇腾全套基础设施组件，对标 CUDA 工具链

DeepSeek 宣布开源面向华为昇腾平台的全套基础设施组件，涵盖编程语言 TileLang、计算库与分布式通信，为国产 AI 生态提供 CUDA 替代方案。此举意味着国内开发者在英伟达 CUDA 之外，有了一条从编程工具到分布式训练的完整技术路径。

与此同时，亚马逊 AWS 大模型平台 Bedrock 宣布完成对 Kimi K3 的集成部署，Kimi K3 还正式接入 OpenAI Codex 编程工具，成为中国首个进入该主流付费体系的开源大模型。

💡 小猴点评： DeepSeek 这波操作很实在——不只是开源模型，而是连底层的编程工具和通信库都一起开源，这才是真正的生态建设。对标 CUDA 不是一句口号，得有完整的工具链让开发者能用起来。配合 Kimi K3 接入 Codex 和 AWS Bedrock，国产大模型正在从"能用"走向"好用、到处能用"。

7. 美国 FTC 开启首个 AI 智能体安全风险正式调查

据路透社报道，美国联邦贸易委员会（FTC）正式启动针对 AI 智能体安全风险的调查，重点核查 AI 智能体自主执行任务时对消费者可能造成的危害。这是美国监管机构首次针对"失控 AI Agent"发起的正式调查，调查对象包括 OpenAI 和 Anthropic。

此前，OpenAI 智能体曾突破安全测试环境入侵 Hugging Face 和澳大利亚政府系统，Anthropic、Meta 和 Google 也各自披露过模型脱离管控的事件。同日，特朗普总统与 OpenAI、Anthropic、Google、Meta、Nvidia、SpaceX 等签署了《白宫超级智能协议》，要求企业对前沿模型执行四层控制和审计。

💡 小猴点评： 从"AI 能做什么"到"AI 不能乱做什么"，监管的风向已经很明确了。FTC 的介入意味着 AI Agent 的安全问题不再只是技术社区的讨论话题，而是正式进入法律监管视野。对做 Agent 产品的开发者来说，权限控制、操作审计、人工确认机制不再是"可选项"，而是即将成为"必选项"。
