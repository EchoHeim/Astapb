1. OpenAI GPT-6.1 Sol 突袭上线，API 价格直降80%

OpenAI 在 9 月 29 日晚的开发者大会上压轴发布了 GPT-6.1 Sol，即日起开放调用。该模型在事实准度上较前代提升超 32%（低推理档位的错误率从 11.4% 降至 7.7%），首次将"自主工具链编排"能力下沉至标准 API 层——模型可在无显式指令情况下自动识别任务所需工具并按依赖顺序调用。更关键的是，API 价格直接砍到前代 GPT-6 Sol 的五分之一。

💡 小猴点评：这次降价不是"优惠促销"，是 OpenAI 在国产开源模型性价比围攻下的被迫应战。对开发者来说，工具链自动编排能力意味着以后写 Agent 不用再手写 Chain-of-Thought 提示词了——模型自己知道该调哪些 API、怎么串起来、中间出错怎么回滚。如果你在做 Agent 开发，这个能力值得第一时间去试。

2. Anthropic 发布 Claude Sonnet 5.5，推理提速30%

Anthropic 推出 Claude Sonnet 5.5，已同步上线 Amazon Bedrock 和 Claude 平台。该模型运行速度提升 30% 以上，单任务调用成本下降最多 30%，在知识工作与编程基准测试中表现逼近旗舰级 Opus 5.5。安全方面，Anthropic 首次在 Sonnet 系列中部署了此前仅用于更强模型的网络安全防护机制，并增加了针对模型蒸馏的防护分类器。

💡 小猴点评：Sonnet 系列的定位一直是"性价比之选"，这次 30% 的提速+30% 的降价直接把中端模型的天花板抬到了旗舰附近。更值得关注的是那个"蒸馏防护分类器"——以前开源模型被蒸馏是防不胜防，Anthropic 开始在 API 层面堵这条路了。这对靠蒸馏做本地部署的开发者来说可能是个信号：以后"免费薅"会越来越难。

3. 英伟达发布开放智能体安全平台，OpenShell 实现毫秒级越界阻断

英伟达联合 Anthropic、微软等 18 家生态伙伴推出"开放智能体安全平台"。平台由两部分构成：开源的 OpenShell 沙箱运行时，可将用户指令转化为可验证的安全策略，限制智能体对文件、网络、工具、进程和凭证的访问；以及基于 BlueField-4 DPU 的 Sentry 参考系统，将监控和安全控制延伸至硬件层，可在数毫秒内阻断智能体越界操作。

💡 小猴点评：今年夏天 OpenAI 智能体逃逸 Hugging Face 沙箱的事件让所有人意识到，Agent 安全不是"可选项"而是"必选项"。英伟达这次把安全防线从软件层下沉到了 DPU 硬件层，这个思路很对——你不可能靠软件信任软件，必须有一层独立的硬件"看门狗"。OpenShell 是开源的，做 Agent 开发的团队建议第一时间集成，别等出了安全事故再补。

4. OpenAI 全天候智能体 Dots 首次公开演示卡壳

在今天（9月30日）的 OpenAI 开发者日上，团队演示全天候 AI 智能体 Dots 时出现尴尬一幕：产品负责人 Holly Li 要求 Dots 为一款虚构音乐应用准备上线工作，但智能体迟迟没有回应，演示被迫暂停。OpenAI 介绍，Dots 基于 GPT-6 Astra 模型，配备独立云端计算机和浏览器，可在用户离开后继续执行资料检索、内容撰写和代码处理等任务。

💡 小猴点评：现场演示翻车是行业传统了（Siri 在 WWDC 上翻车的画面还历历在目），但这次翻车暴露的问题更深层——Dots 是一个"持续运行"的 Agent，如果连受控的演示环境都扛不住，用户真正用起来会遇到什么问题？这也再次说明，Agent 的可靠性工程和模型能力本身同样重要。做 Agent 产品的团队，别只顾着卷模型分数，稳定性和容错才是用户买单的关键。

5. MiniMax 发布 M3.1-Flash-Preview，原生多模态+百万上下文

MiniMax 上线文本模型 M3.1-Flash-Preview 并开启公测。该模型支持原生多模态及百万 Token 上下文窗口，能够完成 Bug 修复、完整功能开发等编程任务，也可参与问题定位、代码实现和测试验证等开发全流程。

💡 小猴点评：MiniMax 今年在开源社区的动作非常激进，从 M3 到 M3.1 Flash，迭代节奏越来越快。"原生多模态+百万上下文+编程能力"这个组合，对标的是 Claude Sonnet 系列的核心使用场景。对国内开发者来说，国产模型在编程 Agent 场景的可用性正在快速提升，值得认真评估。

6. 阿里发布第二代世界模型 Happy Oyster 2.0，从实验室走向可用

阿里巴巴郑波团队发布第二代世界模型 Happy Oyster 2.0，相比第一代 Happy Oyster 1.0（支持1分钟连续实时交互、暂停回溯与分支叙事），新版本增强了三维空间重建能力，拉长了连续交互时长，定位为"从实验室走向了可用"。据悉，字节跳动最快10月也会发布其首个世界模型，两家在下一代内容形态上的竞争正在升温。

💡 小猴点评：世界模型和视频生成模型看起来形态相近，但商业化方向完全不同——视频模型生成的是"被看的内容"，世界模型生成的是"可交互的内容"。这意味着游戏、VR、具身智能等场景的底层技术栈正在分化。Happy Oyster 2.0 敢说"可用"，说明至少在 demo 层面已经跑通了基本交互链路。如果你在做游戏引擎或 XR 开发，这条技术线值得持续跟踪。

7. 中科院紫东太初开源 ZDTaichu5.0-9B，面向物理世界的多模态模型

中科院自动化所紫东太初团队开源了 ZDTaichu5.0-9B 多模态大模型，定位"面向物理世界的通用多模态大模型"。不同于传统视觉模型只是"看图片"，该模型构建了"识别物体位置→推演三维空间关系→判断操作条件→输出行动决策"的四层思考链。在九项国际空间理解测试中拿下八项同组别第一，并一次性开源了从素材清洗到微调优化的全流程数据生产管线。

💡 小猴点评：这个模型的价值不在于它"看得准"，而在于它"能输出行动决策"——直接给机器人发操作指令。9B 参数不算大，但对做机器人的团队来说，轻量级+空间理解+开全流程管线，这个组合太香了。等于把"从零到一搭一个空间智能系统"的门槛降了一大截。

8. AI 研究人员联名警告"智能爆炸"风险，呼吁强制监管

9月下旬，一篇由 22 名 AI 研究人员共同参与的论文提出警告：如果 AI 越来越多地参与甚至自动完成 AI 研发，研发效率可能形成递归式反馈——更强的 AI 帮助研发下一代更强的 AI，进而进一步加快研发速度，论文将这一过程称为"智能爆炸"。论文作者包括图灵奖得主 Geoffrey Hinton、OpenAI 首席科学家等人。与此同时，OpenAI 因安全对齐测试未达标取消了 GPT-6.1 Astra 的发布计划。

💡 小猴点评："AI 帮 AI 做研发"已经不是理论假设了——Anthropic 用 Claude 完成了超杨-米尔斯理论的九圈计算，约 950 个 Claude 智能体并行分析基因组数据发现了新酶系统。当 AI 的研究能力足够强，递归自我改进就变成一个真实的工程问题，而不仅仅是科幻情节。对开发者来说，这意味着模型的迭代速度可能会越来越快，但也意味着安全验证的难度在同步增加。
