## 新增「AI 简报」栏目（唯一入口在首页）

**需求**：首页加一个 AI 简报入口，内容按 `CodeKey/AI 日报/*.md` 生成，每日更新；
简报内容只从这个入口进；生成的 HTML 落在 `WebBlog/docs/AI动态/`，**按月份分文件夹**。

**新增文件**
- `scripts/sync-ai-brief.mjs` —— 生成器（零依赖，只用 node 内置模块，predev/prebuild 自动跑）。
  解析两种原稿格式：纯正文版（9/19、9/20）与带「发布配置」块版（9/21、9/22）。
  提取日期（文件名 `AI日报_M月D日.md`，跨年用「月份 > 当前月则回到上一年」判断）、
  标题（配置块优先，再清洗 `AI日报｜…：` 前缀与 `｜9.21 AI日报` 后缀）、摘要、标签、正文。
  正文会自动剔除：`## 本期未采用`（编辑留档）、结尾纯话题标签行、🐵 署名条（改放标题下方）。
  自带极简 Markdown 渲染器（标题/段落/粗体/行内码/引用/列表/表格/hr/围栏），
  并把 `💡 小猴点评` 领起的那几段整体折成 `<aside class="callout">`。
- `src/pages/AI动态/index.astro` —— 目录页（最新一期大卡 + 按月份分组的行列表）。
- `src/data/ai-brief.json` —— 生成器产出的清单，供首页入口与目录页读取。

**改动的文件**
- `src/pages/index.astro`：hero 与文章列表之间加 `.ai-strip` 入口条（只放期数/最近更新，
  不展开任何简报内容）。
- `src/consts.ts`：新增 `AI_BRIEF`（title/description/lede/tagline/note）。
- `src/styles/global.css`：新增「19. AI 简报入口 / 目录」，另在 760px 断点里给入口卡折行。
- `package.json`：`predev` / `prebuild` 各追加一步 `sync-ai-brief.mjs`；加 `ai:build` 脚本。
- `WebBlog/.gitignore`：忽略 `public/AI动态/`（构建镜像，正本在 docs/）。
- `astro.config.mjs`：sitemap 过滤掉 `/AI动态`（中文路径两种写法都判），与 /search、/404 一致。
- `.github/workflows/publish.yml`：**修掉一个会让「每日更新」失效的坑**（见下）。

**产物落两处的原因（关键设计）**
Astro 只把 `public/` 收进构建产物，不会去 `docs/` 里捞静态文件（那是内容集合的源）。
所以：正本写 `docs/AI动态/YYYY-MM/YYYY-MM-DD.html`（随仓库提交），
再镜像一份到 `public/AI动态/`（已 gitignore）。
**镜像这一步必须无条件执行** —— CI 检出的仓库里 `public/AI动态` 是空的，
只靠 `docs/` 重建镜像，链接才不会 404；源目录不存在时也要跑（已实测）。

**改到的既有 bug：CI 的 `paths-ignore: "CodeKey/**"` 会让日报永远不触发部署**
每天新丢进 `CodeKey/AI 日报/` 的原稿，push 后不会触发 GitHub Pages 重新构建，
线上会一直停在旧内容。GitHub 不允许 `paths` 与 `paths-ignore` 同时用，
所以改成逐个列出素材子目录（`CodeKey/01-IP形象/**` … `07-发布登记/**`），
注意目录级匹配**必须带 `/**`**，只写目录名匹配不到目录里的文件。
漏列新素材目录的后果只是多跑一次构建，不会漏部署。构建步骤里也加了
`dist/AI动态/index.html` 的存在性自检。

**「每日更新」的落地**：建了定时自动化「AI 简报每日更新」（每天 09:00）——
跑生成器 → 只提交 `WebBlog/docs/AI动态`、`WebBlog/src/data/ai-brief.json`（以及未提交的原稿）
→ push master 触发部署；无新增日报时明确不提交、不推送。

- 全站扫描确认「其它位置不出现 AI 简报」：RSS / 搜索索引 / 归档 / 标签 / 关于 / 404 /
  分页 / 侧栏**全部干净**，导航栏（首页 标签 归档 关于 | 导航站 GitHub）未变；
  首页只有 `.ai-entry` 一处。sitemap-0.xml 137 条 URL，不含 AI动态。
- 用临时 Node 静态服务（零依赖）服务 `dist/`，再用无头 Chrome + CDP 截图核对：
  首页入口、目录页、详情页（浅色/深色/真 390px 移动端）渲染均正常。

**本机环境的两个新坑（已写进 local-html-visual-verify skill）**
1. PowerShell 工具重定向（`*>`）会把子进程 UTF-8 输出按 GBK 解码 → 中文全乱码，
   设 `[Console]::OutputEncoding` 也救不回来。要读中文日志就让 Node 自己写文件。
2. 命令里出现 `%E5%8A%A8` 这类百分号编码会被安全过滤直接拦掉（当成 cmd 的 `%VAR%`）；
   中文 URL 要么传字面量，要么用 `[Encoding]::UTF8.GetString([byte[]](...))` 拼。
3. `npm ci` 跑一半会静默卡住（进程在、CPU 在涨、但连续几分钟没有文件写入）。
   判据：`node_modules` 里近 3 分钟被修改的文件数为 0；`Stop-Process` 后重跑，
   缓存命中只要 4 分钟。
