**本机 dev server 的两个坑（都踩过）**
- Astro dev 只监听 **IPv6 的 localhost**：`localhost:4321` 与 `[::1]:4321` 通，
  `127.0.0.1:4321` 一律 ECONNREFUSED。探端口要用 `localhost`。
- Astro 会在 `.astro/dev.json` 里记录运行中的 dev server（pid/port）。
  已有实例在跑时，再起一个会被拒绝并提示 "Another astro dev server is already
  running"，需 `astro dev stop` 或 `--force`。用户自己起的那个（PID 36456）就
  因此把我的临时服务挡住了 —— 探不到服务时先看 `.astro/dev.json`。
