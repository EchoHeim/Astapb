## 首页 hero：logo 移到标题左侧（当日下午）
lodge 要「把 `images/logo.png` 放在主页文字左边，注意排版细节」。改动 2 个文件：
- `index.astro`：hero 结构改成 kicker → `.hero__head`（logo + `<h1 class="hero__title">`）
  → lede → stats；logo `alt=""`（装饰）、给了 `width/height` 防 CLS、不加 lazy（首屏）。
- `global.css`：新增 `.hero__head` / `.hero__logo`，`.hero__head .hero__title{margin-bottom:0}`
  （下间距交给 head，其它页不受影响 —— `hero__title` 全库只有首页用）；≤760px 改纵向
  （logo 居左压在标题上方）。

**两个关键细节（都靠测量定的，不是拍脑袋）**：
1. **logo.png 是不透明白底**（全图 0 透明像素，四角 255,255,255）→ 直接贴就是一块白方块。
   解法：浅色 `mix-blend-mode: multiply`（白底 → `--paper`，墨字不变）；
   暗色 `filter: invert(1) hue-rotate(180deg)` + `mix-blend-mode: screen` 让黑底消失
   —— **hue-rotate 180° 不能省**，否则叶子的绿会翻成品红。实测两主题都无痕。
2. **原图白边很宽**：242×116 里手写内容只占 x34..215 / y15..112（两侧共 60px），
   会把 logo 视觉尺寸压掉近 1/4、并排间距也被撑虚。解法：按**原始像素比例**用负 margin
   抵掉白边，尺寸只由 `--logo-ink` 一个变量控制 ——
   `--k: calc(var(--logo-ink)/182)`，`width: calc(var(--k)*242)`，
   `margin: calc(var(--k)*-15) calc(var(--k)*-26) calc(var(--k)*-3) calc(var(--k)*-34)`。
   这样 gap 就是内容到标题的真实间距，且各处随变量等比缩放、无需另写断点。
- `--logo-ink: clamp(104px, 9.2vw, 132px)`（1440 下内容 132×71，约等于标题单行高 66px）。
