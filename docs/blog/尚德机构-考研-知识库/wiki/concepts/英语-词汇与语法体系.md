# 英语-词汇与语法体系

英语二的地基。这套资料在词汇与语法上的**覆盖度是全库最完整的**——
从词根词缀到 5500 词核心词库，从「春笋班」的 11 讲语法专题到「基础课」的 12 讲精讲，形成了完整梯度。

### 二、语法专题（「春笋班」11 讲 + 基础课精讲 12 讲）

**春笋班语法专题**（按讲次，从词法到句法）：
| 讲次 | 主题 |
| --- | --- |
| 1 | 词类 |
| 2 | 名词 |
| 3 | 冠词 |
| 4 | 代词 |
| 5 | 数词 |
| 6 | 形容词 |
| 7 | 句子 |

| 9 | 名词性从句 |
| 10 | 定语从句 |
| 11 | 被动、倒装、虚拟 |

> 这条线索是**标准的「词法 → 句法 → 特殊句式」演进路径**，11 讲顺序本身就是一份语法学习路线图。

**基础课精讲 12 讲**：以真题阅读段落为语料，讲词汇与长难句。例如「精讲 12」的语料是
一篇关于经济衰退与失业者的英文段落，并配中文翻译全文对照。

### 三、语法知识体系

[[sources/英语/基础课/语法知识体系总结文档]]（21 页，提取 23,282 字符，是全库语法密度最高的文件）

## 解题方法 / 适用场景

- **词汇**：按「词根词缀 → 高频 1500 → 核心 5500」的顺序滚动，考前聚焦高频层。
- **语法**：按春笋班 11 讲顺序过一遍做骨架，再用《语法知识体系总结文档》做查漏补缺。
- **长难句**：基础课精讲 12 讲用的是**真题原文 + 中文对照**，适合作为长难句训练素材。

## 易错点

- 词根词缀类资料有两份（短版 11 页 / 长版 147 页），**先短后长**，不要一上来啃 147 页。
- 语法体系文档与春笋班专题存在**覆盖重叠**，同时用会重复投入时间，建议以一份为主线。
- 「冠词」课件（3MBA英语春笋班冠词）为扫描件，正文未提取。
