> 2019 年管理类联考逻辑推理解析 / 26. 新常态下，消费需求发生深刻变化，消费拉开档次，个性化、 多样化消费渐成主流。 / 在相当一部分消费者那里，对产品质量的追求压倒了对价格的考虑。供给侧结构性改革，说 / 到底是满足需求。低质量的产能必然会过剩，而顺应市场需求不断更新换代的产能不会过剩。 / 根据以上陈述，可以得出一下哪项? / A.只有质优价高的产品才能满足需求。 / B.顺应市场需求不断更新换代的产能不是低质量的产能。 / C.低质量的产能不能满足个性化需求。 / D.只有不断更新换代的产品才能满足个性化、多样化消费的需求。 / E.新常态下， 必须进行供给侧结构性改革。
