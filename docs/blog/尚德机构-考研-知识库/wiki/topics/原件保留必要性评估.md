# 原件保留必要性评估

**结论：不建议删除任何原始文件。** 本页记录做出这个结论的实测依据。

这套 Markdown 知识库的定位是**可检索、可交叉引用的索引层**，**不是原件的替代品**。
把原文件删掉会造成不可逆的信息丢失，理由分三层，全部有实测数据支撑。

---

## 一、有 816 页（11%）根本没转出任何文字

| 类别 | 份数 | 页数 | Markdown 里的状态 |
| --- | --- | --- | --- |
| 纯扫描件（无文字层） | 7 | 794 | 占位页，正文为空 |
| 字体乱码（CID 编码） | 1 | 22 | 占位页，正文为空 |
| **合计** | **8** | **816 / 7,367 = 11%** | **零内容** |

这 8 份里包括**全库唯一的一套官方考纲**（2022 管综 + 英语，含 2 份解析，共 158.66 MB）
和**全库唯一的 2020 英语真题**。删掉原件，这些内容就只剩下一个写着「需 OCR」的空壳。

## 二、图片承载的信息从未进入 Markdown

对 134 份 PDF 逐页做了图片对象的面积审计：

| 指标 | 数值 |
| --- | --- |
| PDF 总页数 | 7,367 |
| 含图片的页 | 3,022（**41%**） |
| PDF 内嵌图片总数 | **6,649 张** |
| 单张图片覆盖页面 >50% 的页 | **1,987（27%）** |
| 整页图片占比 ≥50% 的资料 | 22 份，共 1,763 页 |
| Office 文件内嵌媒体 | 14 份文件中共 **321 个**，25.2 MB |

> [!IMPORTANT] 关键区分：整页图片有两种性质，都不能丢
> **① 冗余栅格化** —— 有些 PDF 把整页幻灯片渲染成一张底图，再把文字作为独立文本层叠在上面。
> 这类页面的**文字**已经被 Markdown 捕获，图片是重复的。
> **② 唯一载体** —— 图表、思维导图、手写笔记、答题卡示意、公式排版。
> 这类页面的内容**只存在于图片里**，Markdown 拿到的是残渣。

### 实测样本（渲染原页与 Markdown 逐字对比）

**样本 A：`1221-考前冲刺/密训资料/【密训资料】管理类联考数学.pdf` 第 3 页**
- 原页：一张排版完整的公式表格，含 $2n,\ n\in Z$、$a^m\cdot a^n=a^{m+n}$、$\frac{a^m}{a^n}=a^{m-n}$、
  $(ab)^n=a^n\cdot b^n$、$a^{-n}=\frac1{a^n}$、$\frac1{\sqrt3-\sqrt2}=\sqrt3+\sqrt2$，以及 ★ / ★★ / ★★★ 难度星标、页眉机构 logo
- Markdown 实际内容：`2n,nZ 2n1,nZ` / `am an amn, amn,(ab)n anbn,( )n  ,` / `分类 a0时，a0 1,an 当 an`
- **判定**：这是数学公式手册，而**运算符（`∈`、`±`、`·`、`+`、`-`、分数线、根号）与上标指数全部丢失**。
  文字是拿到了，但**最核心的数学内容是错的**。

**样本 B：`写作/中文写作基础课件标准化.pdf` 第 6 页**
- 原页：整页是全国硕士研究生入学统一考试**管理类联考答题卡的实拍图**——报考单位/姓名栏、
  考生编号填涂区、1–55 题选择区域、56 题作文方格区，并附涂卡规范与二维码
- Markdown 实际内容：**`考情分析`（仅 4 个字符）**
- **判定**：整页信息量为零。这类页面在幻灯片课件里并不罕见。

## 三、即使标为「完整」的文件，也有 18% 的页面是图片主导

`conversion_status: ok` 只表示「抽到了可读文本」，**不表示「内容完整」**：

| 状态 | 份数 | 图片主导页 / 总页数 | 占比 |
| --- | --- | --- | --- |
| `ok` | 124 | 1,188 / 6,548 | **18%** |
| `scanned_no_text` | 7 | 792 / 794 | 100% |
| `cid_garbled` | 1 | 7 / 22 | 32% |

也就是说：**「转换成功」的文件里，平均每 5 页就有 1 页的视觉内容不在 Markdown 中。**

## 四、还有一个与内容无关、但同样关键的理由

这 149 份原始文件**全部已被 git 跟踪**（`git ls-files` 实测 149 条命中）。

这意味着：

- 从工作区删掉文件，**仓库体积一点都不会变小** —— 二进制块（blob）仍然留在 `.git` 历史里
- 真正的「瘦身」只能靠重写 git 历史（`git filter-repo` / BFG），那是一个**破坏性且影响协作者**的独立操作
- 而你在本地得到的唯一结果，是**失去了唯一一份可读的原件**

**想靠删文件省空间，是个无效操作；想彻底移除，得改历史。这两件事不能混为一谈。**

## 五、知识库与原件应该怎么分工

| 用途 | 用什么 |
| --- | --- |
| 全文搜索、找「哪份资料讲过这个」 | ✅ `markdown/` |
| 跨资料的综合、题型对比、覆盖度判断 | ✅ `wiki/concepts/` `wiki/topics/` |
| 看公式、图表、思维导图、答题卡版式 | ❌ 必须回原件（摘要页 front-matter 的 `original` 字段有路径） |
| 核对数学公式的运算符与指数 | ❌ 必须回原件 |
| 阅读 8 份扫描件的内容 | ❌ 必须回原件（或先 OCR） |

> [!TIP] 摘要页就是为此设计的
> 每份 `wiki/sources/**.md` 的 front-matter 都带 `original:` 字段（指向原件相对路径）
> 和 `pages:`，正文里有 `<!-- page N -->` 页锚点。
> **发现 Markdown 内容可疑时，可以精确定位回原件的第几页。**

## 六、如果确实需要处理体积

按推荐程度排序：

1. **什么都不删**（推荐）。347.93 MB 对一个本地仓库不是问题；
   已经进了 git 历史，删了也不省。
2. **先 OCR 那 8 份（816 页）**，把内容补进 `markdown/`，之后是否保留原件的判断才有依据。
   优先：`22级考试大纲及解析/` 4 份（P0）、`英语/2020英语试题及答案.pdf`（P1）、
   `12月冲刺学习计划.pdf`（P1）。
3. **原件移到仓库外归档**（外置硬盘 / 云盘），保留在本地可访问位置。
   注意：这会让 `git status` 显示 149 条删除，需要另行决定是否提交。
4. **不要把知识库当成原件的替代品去删原件** —— 这是唯一会真正丢数据的选项。
