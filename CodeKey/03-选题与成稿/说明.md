# 03 · 选题与成稿

**这个目录装两样东西：写稿的方法，和写完的稿。**

分层的规则很简单——**根层是方法论，子目录是成稿**。打开就能看见方法论，
不用往下点；成稿按栏目归类，不会和规则混在一起。

```
03-选题与成稿/
├── 选题池.md          # 弹药库：50+ 条待写选题，写之前先来这里挑
├── 标题库.md          # 标题公式、禁词清单、A/B 记录
├── 金句库.md          # 开头钩子、点评口吻、结尾金句
├── 固定模块.md        # 署名条 / 关注引导 / 自动回复 / 菜单文案
├── 实用软件分享/      # 主力栏目（群发），按年月
│   ├── 2026-09/
│   └── 2026-10/
├── 技术干货/          # 储备栏目
│   └── 嵌入式通信/
└── 说明.md
```

## 三条分类规则

| 判断 | 放哪 |
| --- | --- |
| 是「怎么写」的规矩，会被反复查阅 | 根层（选题池 / 标题库 / 金句库 / 固定模块） |
| 是某一篇具体稿子的正文、原稿、排版 | 对应栏目的子目录 |
| 是「哪天发了什么、数据如何」 | **`05-发布登记/`，不在这里** |

**AI 日报的成稿不在这个目录。** 它在 `../AI 日报/`（编号体系外，原因见 README 第 2 条
和 `AI 日报/说明.md`）。别把日报往这里搬。

## 每篇归档什么

工具实测稿是三件套，缺一不可：

```
2026-10/
├── 2026-10-03_VoiceStudio开源语音工作站.md          # 存档：发布配置 + 事实核证表
├── 2026-10-03_VoiceStudio开源语音工作站_正文.md     # 只有正文，可整篇复制粘贴
├── 2026-10-03_VoiceStudio开源语音工作站_排版.html   # 摸鱼绿排版，全内联样式
└── 2026-W40_VoiceStudio_素材原稿.md                # 可选：脚本生成的原始素材
```

文件命名统一 `<日期>_<关键词>`，**日期在前**，这样按文件名排序就是时间顺序。
素材原稿加 `_素材原稿` 后缀，跟定稿区分开。

## 和另外两个目录的区别

| | 02-视觉素材 | 03-选题与成稿 | 05-发布登记 |
| --- | --- | --- | --- |
| 存什么 | 图 | **文字**：方法论 + 成稿正文 | 事实与数字 |
| 会不会被复用 | 会 | 方法论会，成稿不会 | — |
| 改了会不会影响历史 | 会 | **成稿不能改**，方法论可以 | 只增不改 |

不要混着放。混放的后果是同一个素材出现多个版本，三个月后你分不清哪个是终稿。

## 为什么值得归档

1. **复用。** 三个月后的新文章可以直接引用旧文的图和段落，不用重做。
2. **复盘。** `05-发布登记/往期数据.csv` 只记数字，要回看「当时到底怎么写的」
   就得靠这里的定稿。
3. **合集。** 攒够 30 篇后可以出一份「年度精选」合集，归档齐了才能选。
