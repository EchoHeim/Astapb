# Windows 终端美化，Oh My Posh 装完满屏方块怎么解决

🐵 **程序小猴 · 实用软件分享**

我这半年几乎每天都盯着这一行。

```text
PS C:\Users\lodge>
```

灰底白字，毫无信息量。要确认自己在哪个分支，得敲一次 `git status`；要确认上一条命令成没成功，得回头翻屏。一天下来这种小动作能重复几十次。

后来我把提示符换成了 Oh My Posh。装完第一反应是好看。用了一周才发现，好看是附带的，真正省掉的是那些「敲一下才知道」的命令。

---

## 装它只要两行

Windows 上用 winget 直接装。

```bash
winget install JanDeDobbeleer.OhMyPosh
```

装完还没生效，要让 PowerShell 每次启动时加载它。打开配置文件。

```powershell
notepad $PROFILE
```

在里面加一行。

```powershell
oh-my-posh init pwsh | Invoke-Expression
```

保存，重开一个终端窗口，提示符就变了。

如果 `$PROFILE` 这个文件不存在，先跑一次 `New-Item -Path $PROFILE -Type File -Force` 把它建出来。我第一次就卡在这一步，记事本弹了个「文件不存在」，愣了半天。

---

## 重开窗口，满屏都是方块

这一步最容易劝退，也是我踩的第一个坑。

装完打开终端，屏幕上没有漂亮的提示符，只有一排框。

```text
□□□□ main □□ □□
```

软件没坏。Oh My Posh 用了大量 Nerd Font 的特殊字符，那些三角箭头、分支符号、语言图标，普通字体里根本没有这些字形，渲染不出来就变成方块或者问号。

**装字体，再把终端字体改成它。两件事都得做，少一件都不行。**

随便挑一个 Nerd Font 装，常见的三个。

```text
JetBrainsMono Nerd Font
CaskaydiaCove Nerd Font
MesloLGM Nerd Font
```

装完字体还不算完，得回 Windows Terminal 的设置里把字体改成它。漏了这一步，你会以为安装失败。我第一次就漏了，还跑去 GitHub 翻 issue 列表，翻了二十分钟才反应过来是自己没换字体。

我用的是 JetBrainsMono。换完字体那一刻，方块全变成正常图标，才算真的开始。

### 装完不对劲，按这个顺序查

| 现象 | 最可能的原因 | 怎么确认 |
| --- | --- | --- |
| 提示符完全没变 | `$PROFILE` 没写对，或没重开窗口 | 在终端跑 `$PROFILE` 看路径存在不存在 |
| 满屏方块 / 问号 | 字体没装，或装了但没在终端里选 | 设置 → 外观 → 字体，看选的是不是 Nerd Font |
| 有图标但颜色发灰 | 主题没加载 | 跑 `$env:POSH_THEME`，没输出就是走的默认配置 |
| 分支信息不显示 | 当前目录不是 Git 仓库 | `cd` 进一个仓库再看 |
| 每次开终端要等一两秒 | 某个 Segment 在扫文件系统或访问网络 | 关掉耗时类 Segment 逐个试 |

## 提示符上现在有什么

换完之后那一行长这样。

```text
 lodge  D:\Projects\GlueDetect   main +2 ~1
❯
```

`main` 是分支，`+2 ~1` 是有两个新文件、一个文件被改过。这些平时要敲 `git status` 才看得到，现在抬眼就是。

进目录还会自动显示 Python 版本、Node 版本、上一条命令的执行耗时、当前时间。我特意把耗时那一段留下了，跑脚本的时候能直接看出哪一步慢，不用再掐表。

有一次在同事旁边开终端，他问我这行是怎么配的。我说装了个东西，他以为是主题皮肤。我让他切进一个 Git 仓库看一眼，他没说话，第二天自己也装了。

---

## 提示符是一串组件拼起来的

整个提示符可以理解成一排小组件。

```text
[系统] [用户] [目录] [Git] [Python] [状态] [时间]
```

每个组件都能单独开关，能改颜色、改图标、改显示格式，还能设条件。只在 Git 仓库里显示 Git 那段，只在 Python 项目里显示 Python 版本。

所以它既能做成信息很满的一长条，也能做得非常克制。

```text
D:\Code\Project   main
❯
```

我自己最后砍到只剩目录、Git、执行状态、耗时四项。加得越多越花哨，看久了越烦。这句话是我用了两周之后才想明白的，一开始恨不得把所有能显示的全堆上去，结果每次开终端先被一堆图标糊一脸。

---

## 别从零写配置，先抄一个主题

官方仓库里现成的主题已经很多了，`tokyonight_storm`、`unicorn`、`wholespace`、`ys` 都在里面。数量多到项目方明确表示不再接受新的主题投稿。

想挨个看效果，终端里敲这个。

```powershell
Get-PoshThemes
```

它会把所有主题的效果打一遍，挑到顺眼的记下名字，改配置里的 theme 字段就行。

```text
找一个喜欢的主题
      ↓
直接用
      ↓
删掉不需要的模块
      ↓
调颜色和图标
```

十几分钟就能出来一套能用的。我一开始硬啃配置项，啃了一晚上；后来换成改主题，四十分钟搞定，效果还更好。这个顺序别弄反。

---

## 配置文件在哪，改完怎么生效

主题名和组件都写在一个 json 文件里。想知道当前用的是哪一份，敲这个。

```powershell
$env:POSH_THEME
```

没有输出，说明走的是默认配置。想自己指定一份，就在 `$PROFILE` 那行里带上参数。

```powershell
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\tokyonight_storm.omp.json" | Invoke-Expression
```

改完 json 保存，重开一个终端窗口就能看到效果，不用重启电脑。

我把这份 json 丢进了 dotfiles 仓库，换机器的时候拉下来就能用，省得每次重新调。VS Code 的集成终端同样吃这一套，不用另外配。

---

## 为什么它不卡

提示符每敲一次命令就要重新生成一次。如果它是靠一堆 Shell 脚本堆出来的，终端会明显发涩。

Oh My Posh 主体用 Go 写，编译成原生程序跑，缓存、Git 状态、颜色渲染都是内部实现的。它更像一个完整的 Prompt 引擎，不是美化插件。

这句有个前提。你要是自己配了几十个要去扫文件系统或者访问网络的 Segment，该卡还是会卡。够用就好，别为了炫技全开。

---

## 和 Starship 怎么选

研究过终端美化的大概都听过 Starship。两个我都用过一段时间，说几个能实际影响选择的差别。

| 对比项 | Oh My Posh | Starship |
| --- | --- | --- |
| 配置文件 | JSON，可拆多个文件复用 | 单个 TOML |
| 现成主题 | 官方仓库上百个，可直接 `Get-PoshThemes` 预览 | 内置预设约十来个，主要靠自己配 |
| 上手成本 | 稍高，概念多一层（Segment） | 更低，改一个文件就完事 |
| Windows 适配 | 官方一等支持，文档按 Shell 分册 | 支持，但文档偏 Unix |
| 想改细节 | 每个 Segment 都能单独写条件 | 也能改，写法更紧凑 |

想省事就 Starship。想要主题多、能折腾、Powerline 那股利落劲，尤其在 Windows 加 PowerShell 这套组合下，Oh My Posh 更合适。

---

## 跨平台这件事

它支持 PowerShell、Bash、Zsh、Fish。同一套配置思路能跨 Windows、WSL、Linux 服务器用，经常在几台机器之间切的人会喜欢这点。开源协议是 MIT，商用没问题。

说回最开始那行 `PS C:\Users\lodge>`。现在开终端第一眼就知道自己在哪个分支、上一条命令成没成。那行灰字，我是回不去了。
