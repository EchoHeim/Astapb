# 02 · 视觉素材

**一切与「看起来怎么样」有关的素材，以及反复复用的文字模板。** 原来拆成「封面模板」和「正文插图」
两个编号目录，但它们性质相同（都是图、都要复用、都只是还没攒起来），合并成一个，按用途分子目录。

```
02-样式素材/
├── 封面与版式模板/    # 三栏目封面 + 署名条 + 三连引导图
├── 正文插图/          # 架构图、流程图、代码截图
├── 文案模板/          # 金句库 + 固定模块（2026-10-12 从 03-选题与成稿 移入）
├── handraw-style/     # 手绘风格编号库（366 风格 / 170 版式 / 36 主题色），带本地画库
└── 说明.md
```

三个子目录各有一份 `说明.md`，进去看具体规范（尺寸、命名、配色）。

## 三者的区别

| | 封面与版式模板 | 正文插图 | 文案模板 |
| --- | --- | --- | --- |
| 存什么 | 封面、署名条、引导图 | 文章配图 | 金句、固定文案 |
| 出现频率 | 每篇都要用 | 按需 | 每篇都要用 |
| 是否复用 | 模板化，反复用 | 大部分一次性，少部分可复用 | 模板化，反复用 |

> 封面与版式模板的**五件套已建**（2026-10-12：两套封面 + 署名条 + 三连图 + 往期图），
> 可编辑源文件见其子目录说明.md。正文插图仍待建。

## handraw-style/ 是什么

第三方 Skill 包（[yang0/handraw-style](https://github.com/yang0/handraw-style)，v1.9.6），**不是自产素材，是一套配图工具**：
366 种画风 + 170 种版式 + 36 种主题色 + 36 张四宫格参考图，靠编号调用。

- **入口：** 根目录双击 `CodeKey/风格画廊.html`，从那里进画廊挑编号。
- **用法：** 把编号告诉 AI ——「`FA-018` 风格，主题：xxx」。默认只出提示词，说「直接生成图片」才出图。
- **老编号：** 1–366 现在都换了分类码（`FA-001`…`FI-034`），旧号能自动映射，267 = `FE-060`。
- **为什么不进 git：** 整包 50.9 MB / 1025 个文件，属于可重新下载的上游资源；本仓库 `.git` 已 357 MB。
  已在 `CodeKey/.gitignore` 里排除，需要时按上面的仓库地址重装。
- **跟其他三目录的关系：** 它产出的是「画风 / 版式」，成品图仍归 `正文插图/` 和 `封面与版式模板/`。

## 必须遵守的两条

1. **图片进仓库，不要引用外部地址。** 历史上的教训：`FPGA/verilog.md` 里 22 张图
   全部引用了 GitHub 附件地址，源仓库一变更就 22/22 全 404，且无法追回。
2. **截图要重新截，不要放大原图。** 低清图在手机上比缺图更伤观感。

## 现在最该补的三类图

文章大量来自 `WebBlog/docs/`，原稿里的图很多是**手机拍屏或低清截图**，
转公众号时会被压得更糊。优先重做这三类：

| 类型 | 用途 |
| --- | --- |
| 环境搭建流程 | 每篇「从零搭建」类文章的骨架，竖版 5–7 步 |
| 硬件连接拓扑 | stm32mp157 / 树莓派选题，标出引脚与信号方向 |
| 代码前后对比 | 踩坑类文章的核心，左「改前」右「改后」，只留关键几行 |
