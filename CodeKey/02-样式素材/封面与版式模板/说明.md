# 封面与版式模板（02-视觉素材/）

封面是**读者在消息列表里唯一能看到的画面**。同一栏目永远用同一套版式，
目标是「刷到就知道是你」——这是建立品牌识别成本最低的方式。

## 需要做的三套封面

微信封面在消息列表里是 **900×383**（2.35:1），但分享到会话/朋友圈会裁成 **1:1**。
所以**核心信息必须放在中间正方形区域内**，两侧只能放装饰。

| 模板                    | 适用栏目     | 主色           | 固定元素                                     | 主标题区                      |
| ----------------------- | ------------ | -------------- | -------------------------------------------- | ----------------------------- |
| `AI日报_封面模板.png`   | 小猴 AI 日报 | 深绿 `#06872D` | 左上「小猴 AI 日报」＋日期、右下小猴头像     | 中央正方形内，主标题 2 行以内 |
| `技术干货_封面模板.png` | 小猴拆代码   | 墨绿 `#16201A` | 左上「小猴拆代码」＋分类标签、底部小猴线条稿 | 中央正方形内，主标题 2 行以内 |
| `猴米漫谈_封面模板.png` | 猴米打工记   | 浅底 `#FAEEDA` | 整幅表情包图 + 右下角栏目名                  | 底部一行短句                  |

## 版式原则

1. **栏目名位置固定**，三个模板都在左上，字号一致 —— 滑动时的视觉锚点。
2. **主标题字数上限 14 字**（超过在手机上会挤成三行，反而看不清）。
3. **不要在封面上放正文里已有的大段文字**，封面只负责「让人停下来」。
4. 周刊/系列可在右上角加期号（如 `VOL.03`），强化「追更」感。

### 品牌尾图（2026-10-23 新建，和三连图是两种定位）

`尾图_程序小猴_1080x500_20261023.jpg` —— 结构照搬《燕云十六声》尾图：
**左右两端各一个出口（左转化 / 右传播），中间留形象做呼吸，且一个功能图标都不画**。
赞/在看/分享按钮微信正文底部本来就有，图里再画一遍等于把说明书贴在按钮上。

| | 文末三连引导图 | 品牌尾图 |
| --- | --- | --- |
| 尺寸 | 750×163（手机上约 57pt 高） | 1080×500（手机上约 174pt 高） |
| 角色 | 轻量动作条，日常每篇都挂 | 重形象页，占屏明显 |
| 用处 | 常规收尾 | 系列收口 / 需要强引导的文章 |

**生成方式**：`_src/footer/build_footer.py`。AI 只出 3D 场景底图（不含任何文字），
资料卡与**全部中文由代码绘制**——让模型直接写「78篇原创内容」「小猴随心记」这类字必糊，
还改一个字就得重画整张。换账号数据 / 换引导语改脚本常量区重跑即覆盖。

字号是按手机可读性定的（1080 宽缩到 375pt 约 0.35 倍）：底部大字 36px≈12.6pt、
小字 19px≈6.6pt。**资料卡内的字在手机上必然看不清，它只是造型**，别为了"看清"把字号往上堆。

## 正文配图规格（和封面是两套标准）

封面是给消息列表看的，正文图是给已经点进来的人看的，尺寸规则完全不同：

| 位置                   | 规格                | 为什么                                              |
| ---------------------- | ------------------- | --------------------------------------------------- |
| 正文配图（文首条 / 文末图 / 插图） | 宽 **750px**（@2x） | 手机正文区约 375pt 宽，750px 正好 2 倍图，铺满不留白 |
| 封面                   | 900×383             | 消息列表 2.35:1，中间正方形是分享裁切区              |
| 单张体积               | ≤ 300 KB            | 大图拖慢加载，正文里几张图叠起来更明显              |
| 格式                   | 照片/水墨类 **JPG q88~90**；线稿/图表 PNG | 水墨纸纹用 PNG 同尺寸要 800KB+，q90 手机上肉眼无差 |

> **本节是全仓库正文图的唯一标准**，`../正文插图/说明.md` 与
> `../../03-选题与成稿/推文素材/一句一画/_栏目方案.md` 的 7.1 节都以此为准。
> 批量适配脚本：`03-选题与成稿/推文素材/一句一画/_适配公众号.py`。


三条硬规则：

1. **宽度不要小于 750**。窄图在正文里按原尺寸居中显示，两侧会露白边，看着像没对齐。
2. **超过正文宽度只会等比缩小，不会被裁**，所以宁可给足宽度。
3. **高度按内容定**：两行内容 4:1～5:1，单行 6:1 左右。再扁就危险——旧版 540×70（7.7:1）在手机上只有 48pt 高，字全糊成一团。

## 一句一画封面（栏目专属，2026-10-22 建）

唐诗栏目「一句一画」的 50 张封面不走上面那三套绿调模板，单独一套：

| 项 | 值 |
| --- | --- |
| 尺寸 | 900×383，PNG，实测 27~40KB |
| 安全区 | 中 383×383 放「一句一画 NN / 诗题 / 朝代·作者」，左右两侧为可牺牲区 |
| 配色 | 纸白 `#F7F3EA` + 墨 `#222624` + 朱砂 `#B7442E`（**不用品牌绿**，绿是日报/工具文调性） |
| 字体 | 楷体 `simkai.ttf`（古典题材），小字用微软雅黑 Light |
| 版式 | 50 张完全统一，靠诗题与名句区分；淡墨底纹按诗序号取种子，一诗一墨 |
| 生成 | `03-选题与成稿/推文素材/一句一画/_做封面.py` |

断行规则见该栏目 `_栏目方案.md` 7.3 节。改版式重跑脚本即覆盖全部 50 张。

## 制作约定

- 源文件（PSD / Figma / 可编辑格式）也放这里，命名为 `xxx_源文件.psd`，不要只留导出的 PNG。
- 导出尺寸统一 900×383、PNG、体积压到 300 KB 以内（大图会拖慢公众号加载）。
- 改版时**新增文件名带日期**（`AI日报_封面模板_20261001.png`），不要直接覆盖旧的，方便回退。

## ★ 可编辑源文件（2026-10-12 建）

五件套（两套封面 + 署名条 + 三连图 + 往期图）的可编辑源文件在 Ardot 设计稿：
**https://ardot.tencent.com/file/735537841369949**（文件名「CodeKey 封面与版式模板」）。

- 画布按 2 倍尺寸设计（封面 1800×766），导出时缩到 900×383。
- 每篇发文**只改标题两行文字**（示例文案：AI 日报「Claude 4.5 发布 / 编程榜登顶」；
  实用软件「U 盘重装系统 / 一条命令搞定」），其余元素不动，改完重新导出 PNG。
- 封面上有虚线框标出的**中央正方形安全区 766×766（=1:1 裁切区）**，主标题必须留在框内。
- 小猴形象取自 `../../01-IP形象/微信表情包/打工小猴/`（001 / 015 / 020），不要换图。
