## 待办：给每张图换语义名

现在的文件名还是 uuid（`001-ced5-46c5-…png`），不可读、不可检索，
上架表情平台时还要手工改名。脚本已就绪（起点已指向 `01-IP形象/微信表情包`）：

```bash
# 1. 先预览，确认要改哪些
node CodeKey/04-运营方案/tools/rename-assets.mjs

# 2. 去掉 uuid，改成纯序号 001.png（每套独立编号）
node CodeKey/04-运营方案/tools/rename-assets.mjs --apply

# 3. 在 04-运营方案/命名对照表.md 里填语义名，然后落地
node CodeKey/04-运营方案/tools/rename-assets.mjs --apply --semantic
```

## 命名规范

`<三位序号>-<语义名>.png`，如 `001-摸鱼.png`。序号**每套独立**从 001 开始
（微信表情开放平台是按套提交的）。

语义名只写中文/英文/数字，不要带 `-`、`/`、空格。
