**VMware Workstation Pro 现在完全免费，连 license key 都不用填了。**

这不是小道消息。Broadcom 在 26H1 的官方说明里写得很直白，free for commercial, educational, and personal use，后面还跟着一句 You no longer require a license key。

个人、商用、教育都不花钱，也不用再填激活码。

麻烦的地方在下载。你得先有一个 Broadcom 账号，登录之后还未必找得到入口。

更麻烦的是，现在能搜到的教程大多是 2024 年那一版。里面的链接已经失效，安装步骤也少了一块，照着做，第一步就卡住。

我把整个流程重新走了一遍，下面是最新的版本。

**什么时候你会真的用到它**

如果你手上只有一台主力机，虚拟机解决的是这几个麻烦。

· 某个烧录工具、配置软件只有 Windows 版，Linux 下跑不起来
· 想试一个新发行版或者新内核，又不想在主系统上冒险
· 要跑来源不明的程序，扔进虚拟机里隔离掉

这三件事的共同点是不想动主系统。虚拟机的好处也在这，搞崩了删掉重建，宿主一点事没有。

**免费到什么程度**

先把这件事说清楚，免得被旧文章带偏。免费不是一步到位的，中间改过两次。

| 时间 | 发生了什么 | 对你的意义 |
| --- | --- | --- |
| 2024-05-14 | Workstation Pro 与 Fusion Pro 对个人免费 | 家庭和学校场景能白用 |
| 2024-11-11 | 免费范围扩到商用与教育 | 公司里装也不用买授权 |
| 2026-05-14 | 26H1 发布，取消 license key | 装上就能用，没有激活这一步 |

如果你的印象还停在「免费但只能个人用」，可以更新一下了。前两年花两百块买过正版的人，现在是什么心情？

**下载，三个最容易卡住的地方**

入口只有一个，Broadcom 的支持门户。域名是 support.broadcom.com。

2024 年那批 vmware.com 和 customerconnect 的地址已经全部作废，从那些链接进不去。

流程本身不复杂。注册一个免费账号，登录，进 My Downloads，选 Free Software Downloads。但每一步都有坑。

| 卡在哪 | 原因 | 怎么解 |
| --- | --- | --- |
| 登录后找不到下载页 | 免费产品默认不显示在常规下载列表里 | 直接搜产品名，或者走 Free Software Downloads 入口 |
| 页面打开了，按钮点不动 | 条款没有勾选 | 展开版本列表，勾上 I agree to the Terms and Conditions，链接才会亮 |
| 点进去跳回登录页 | 用的是旧地址 | 一律从 support.broadcom.com 重新进 |
| 要求补全资料 | 账号信息不全 | 按要求补完，部分情况还要过一遍出口合规表单 |

后两条特别常见。很多人以为是账号出了问题，换链接、补资料就解决了。

直达链接我放在文末的「阅读原文」里，点一下就到。

**装哪个版本**

别选错，装错了等于白下。

| 你的电脑 | 该装哪个 | 说明 |
| --- | --- | --- |
| Windows / Linux | VMware Workstation Pro | 26H1 起 Windows 版是纯 64 位应用 |
| Mac | VMware Fusion Pro | 和 Workstation 同一批免费 |

版本号的写法也变了。以前是 17.6 那种数字，现在改成 25H2、26H1 这种日历式命名。

如果你还在用 17.x，升级之前先确认自己的虚拟机还在支持范围里。另外 17.6.4 之前的版本有过安全修复，不建议再当主力用。

**安装前先看这三条**

这三件事老教程基本不写，但真正会拦住人。

| 项 | 要求 | 不满足会怎样 |
| --- | --- | --- |
| CPU 虚拟化 | 进 BIOS 或 UEFI，打开 VT-x 或 AMD-V | 装完建不了虚拟机，或者提示硬件不支持 |
| Hyper-V | Windows 上建议关掉 | 两个都在抢虚拟化能力，可能启动失败或者性能异常 |
| 磁盘空间 | 虚拟磁盘放非系统盘，预留足够空间 | 系统盘被撑满，宿主和虚拟机一起卡 |

第一条最要紧。不少人装完能建虚拟机，一开机就报错，回头查半天，问题出在 BIOS 里一个没打开的开关上。

**Linux 主机多两步**

如果你装的是 Linux 版，还有两件事要提前准备。

| 项 | 说明 |
| --- | --- |
| 编译环境 | 装好内核头文件和 gcc，首次启动会编译内核模块 |
| 内核更新后 | 换了新内核要重新编译模块，否则虚拟机起不来 |

这两条不满足的话，安装过程会直接报错退出。

**装完立刻看一眼版本号**

先别急着建虚拟机，打开关于页面确认一下。

| 检查项 | 应该是 |
| --- | --- |
| 版本号 | 26H1u1，Build 25688693，或者更新 |

为什么一定要看这一眼？26H1u1 修掉了两个漏洞，编号是 CVE-2026-59346 和 CVE-2026-59347。走的是从虚拟机内部打到宿主机的那条路。

一个和 VMXNET3 网卡有关，一个和宿主机跟虚拟机之间的文件共享有关。对跑来源不明系统的人来说，这两个洞不是小事。

这个更新是 2026 年 9 月 3 日发的，如果你下到的是更早的版本，建议直接重下一次。

**从旧版本升级，有一个坑**

Broadcom 在 26H1 的已知问题里写了一条。升级时如果安装路径和以前不一样，旧目录里的 ISO 文件不会被自动清掉。

官方举的例子是 C 盘的 Program Files (x86) 目录下那个 windows.iso，会一直留着占空间。

解决办法有两个。升级前先卸载旧版并选择保留配置，或者升级完手动去旧目录清一次。

**免费不等于什么都送**

边界也说清楚，免得后面有落差。

免费的是软件本身的使用权，企业级技术支持和响应时限不包含在内，需要的话要另外买。

另外，虚拟机里装的操作系统和软件，授权各自算各自的，这件事跟 VMware 免费没有关系。

**绕一圈回到开头那句话。软件免费了，license key 取消了，剩下的门槛只有两件事，找到那个下载入口，确认 BIOS 里那个开关。两件事都做完，剩下的就是挑个系统装进去。**
