# 05 · 栏目素材

**已发布内容的定稿归档**，按栏目 + 年月分目录。

```
05-栏目素材/
├── AI日报/
│   └── 2026-09/
├── 技术干货/
│   └── 2026-09/
└── 猴米漫谈/
    └── 2026-09/
```

## 与 03 的区别

| | 03-正文插图 | 05-栏目素材 |
| --- | --- | --- |
| 存什么 | **可复用的素材**（图、表） | **已发布的定稿**（这一期最终发出去的东西） |
| 会不会被别的文章复用 | 会 | 不会 |
| 改了会不会影响历史 | 会 | **不能改** |

**不要混着放。** 混放的后果是同一个素材出现多个版本，三个月后你分不清哪个是终稿。

## 每期归档什么

```
2026-09/
├── 2026-09-19_昇腾960.md          # 定稿正文（Markdown 或纯文本）
├── 2026-09-19_封面.png            # 本期实际使用的封面
└── 2026-09-19_数据.md             # 可选：发出后 24h 的数据 + 一句复盘
```

文件命名统一 `<日期>_<关键词>`，**日期在前**，这样按文件名排序就是时间顺序。

## 为什么值得归档

1. **复用。** 三个月后的新文章可以直接引用旧文的图和段落，不用重做。
2. **复盘。** 数据表（`04-选题与文案库/往期数据.csv`）只记数字，
   要回看「当时到底怎么写的」就得靠这里的定稿。
3. **合集。** 攒够 30 篇后可以出一份「年度精选」合集，归档齐了才能选。

## 关于 AI 日报

日报素材体积小但数量大（工作日日更 ≈ 每月 22 篇），建议：

- 正文可以只存 Markdown，不用存配图（日报配图基本不复用）
- 每月底把当月所有日报的**标题 + 阅读量**合成一行小结存到当月的 `_月度小结.md`
- 这样一年后有 12 行，能直接看出哪个月的热点最带量
