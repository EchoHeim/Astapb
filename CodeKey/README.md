## 文件命名现状

| 目录 | 命名方式 |
| --- | --- |
| `打工小猴/`、`猴米懂礼貌/` | `序号-uuid.png`，如 `001-ced5-46c5-bbc2-a017ae152f74.png` |
| `猴米上学记/` | `<数字串>-uuid.png`，编号不连续 |
| `微信表情包/` 根目录 | 两张散落的表情图，未归入任何子目录 |

**建议统一为 `序号-语义名.png`**（如 `001-打招呼.png`）。现在的 `uuid` 段没有可读性，
上架微信表情包平台、写脚本批处理、做版本对比时都不方便。
另外有几处疑似手误，建议顺手修正：

- `537741e4-72be-45219-8728-21c1ae73abf9.png` 与 `537741e4-72be-4529-8728-21c1ae73abf9.png`
  仅差一位数字，极易混淆；
- `06de1695qq5d7c-4e35-b24b-e3e69de3ea11.png` 中混入了多余的 `qq`；
- `222222cc-753d-409d-9742-8ca9147f8a89.png` 与同目录的纯数字编号风格不一致。

## 使用须知

### 空目录不会进版本库

`AI 日报/` 目前是**空目录**，而 git **不跟踪空目录** ——
它只存在于你本地，别人克隆仓库后根本看不到。若要保持这个分类存在，
在目录里放一个 `.gitkeep` 或一份 `说明.md`。

同理适用于 `WebSite/icon/` 下几个空目录。

### 中文路径

仓库里有中文目录与文件名。在 Windows 上建议先执行：

```bash
git config core.quotepath false
```

否则 `git status` / `git log` 会把中文路径显示成 `\346\226\207...` 转义序列。
通过 GitHub 网页或 CDN 访问这类路径时，需要做 URL 编码。

### 体积

图片素材累计约 **17 MB**，目前无压力。但请注意：

- GitHub **单个文件超过 100 MB 会被直接拒绝**；
- 仓库总体积已接近建议上限（`docs/` 415 MB + git 历史 356 MB），
  素材持续增长会加速逼近；
- **一旦提交进 git，就只能靠重写历史来回收空间**，删文件不会让仓库变小；
- 若素材会持续变大，更合适的位置是独立私有仓库或对象存储，而不是主仓库。
