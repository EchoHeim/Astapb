# 07 · 发布登记

**目的只有一个：发之前先查一下，别再重复发。**

2026 年 9 月这一个月里，「程序小猴」出现过 **两对同主题重复推送**：

| 日期 | 情况 | 后果 |
| --- | --- | --- |
| 09-17 | 同一标题推了两遍（68 阅读 + 3 阅读） | 自己和自己抢曝光；其中一篇送达阅读率 0%，疑似只「发布」未「群发」 |
| 09-19 | 同主题、**两个不同标题**（7 阅读 + 4 阅读） | 加起来才 11 个阅读，合并成一篇质量会更高 |

第二对最危险——**两个标题长得不一样，肉眼是看不出来的**。所以这里不靠标题查重，
而是给每个主题一个唯一标识，靠标识来判断。

---

## 文件

| 文件 | 作用 |
| --- | --- |
| `发布登记表.csv` | 唯一事实来源。**发出去的每一篇都补一行** |
| `check-publish.mjs` | 发布前查重。比对登记表 + `CodeKey/AI 日报/` + `WebBlog/docs/` |

## 表结构

| 列 | 说明 |
| --- | --- |
| 发布日期 | `YYYY-MM-DD` |
| 平台 | `公众号` / `博客` / `知乎` / `掘金` / `小红书` |
| 栏目 | `工具实测` / `AI日报` / `拆代码` / `其他` |
| 标题 | 实际发出的标题，原文照抄 |
| **主题标识** | **查重的核心。同一主题在整张表里只能出现一次** |
| 关键词 | 用 `\|` 分隔，3–5 个，取最能代表主题的词 |
| 备注 | 数据表现、异常情况等 |

## 主题标识怎么起（关键）

**规则：同一个标识在表里只能出现一次。** 出现第二次就说明你在重复发同一件事。

| 栏目 | 命名格式 | 例 |
| --- | --- | --- |
| AI 日报 | `ai-daily-YYYYMMDD` | `ai-daily-20260916`（日期天然唯一） |
| 工具实测 | `tool-<工具名>` | `tool-office-tool-plus`、`tool-workbuddy` |
| 拆代码 | `code-<主题>` | `code-扩展根分区`、`code-crontab` |
| 其他 | `other-<主题>` | `other-20260918` |

工具名的标识**永久占用**：用过 `tool-office-tool-plus` 之后，
就不该再做第二篇 Office Tool Plus——除非是明确的「续」，那就换成 `tool-office-tool-plus-2`。

## 发布流程（三步）

```bash
# 1) 查重 —— 有高风险会返回退出码 1，可以先处理再发
node CodeKey/07-发布登记/check-publish.mjs "候选标题" \
  --topic=tool-office-tool-plus --date=2026-09-21

# 2) 确认没问题就发

# 3) 发完立刻补登记（不要攒，攒了一定会忘）
```

查重会报四类风险：

| 等级 | 触发条件 |
| --- | --- |
| ❌ 高 | 同一天同平台已经发过 · 主题标识重复 · 标题完全相同或高度相似 |
| ⚠️ 中 | 标题部分相似 · 关键词重合 ≥2 个 · 博客/草稿里已有同题 |
| · 低 | 其他部分相似的条目，供参考 |

> 「博客里已有同题」是**中风险而非高危**——博客和公众号本就是同一份内容的不同形态，
> 这是预期内的。它只是提醒你：这篇是改写，不是新写，别把博客原文直接粘过来。

## 看登记表摘要

```bash
node CodeKey/07-发布登记/check-publish.mjs --list
```

除了列全部记录，它还会**自动检查历史重复**：

```
⚠️ 主题标识重复（历史重复推送）：
  tool-workbuddy → 2 次
  tool-office-tool-plus → 2 次
```

这两行就是 9 月那两对重复推送。以后每月跑一次 `--list`，有重复会自己冒出来。

---

## 另外两条防重复的纪律

1. **一天只发一篇。** 9/19 那两篇加起来 11 个阅读；同一天发两篇不会得到两倍的曝光，
   只会让两篇互相分流，还会让读者觉得你在刷屏。
2. **发之前确认走的是「群发」不是「发布」。** 9/17 那篇重复的送达阅读率是 0% —
   只「发布」的文章只出现在主页，不会推送，也基本不会有人看到。

## 和 05-栏目素材 的区别

| | 05-栏目素材 | 07-发布登记 |
| --- | --- | --- |
| 存什么 | **内容本身**（定稿正文、封面、配图） | **事实记录**（发过什么、什么时候、主题是什么） |
| 体积 | 大 | 极小，纯文本 |
| 用途 | 复用、归档、出合集 | **查重、防重复推送** |
| 出现频率 | 偶尔打开 | **每篇发布前都要打开** |

不要合并——查重表要足够轻、足够快，才能每次都愿意看一眼。
