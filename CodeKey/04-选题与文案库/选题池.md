# 选题池

> 「小猴拆代码」与「猴米打工记」的选题弹药库。
> 素材来源：`WebBlog/docs/`（106 个 md，其中 104 篇为自有内容）。

## 怎么用

1. **写作前先来这里挑**，不要临时想题目。临时想的题目质量一定低于沉淀过的。
2. 每篇发布后回来更新「状态」，好的题材把标题模式记到 `标题库.md`。
3. 有新想法随时往储备池里丢，**宁可多存，不要现找**。

状态流转：`待写` → `写作中` → `已发布` → `已放弃`（放弃要写明原因，避免重复踩）

## 选题评估三问

三关全过再动手，任何一关不过就先放回池子：

| 问题 | 不过关意味着 |
| --- | --- |
| ① 有人会去搜这个关键词吗？ | 没有搜索需求 = 只能吃会话流量，天花板极低 |
| ② 是「一个具体问题」还是「一个知识领域」？ | 「Linux 内存管理」不是选题，「根分区满了怎么扩容」才是 |
| ③ 我有别人没有的一手经历吗？ | 二手转载拼不过大号，你赢在「这个坑我真踩过」 |
