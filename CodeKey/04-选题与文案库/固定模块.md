# 固定模块

**每篇文章都要用的文案，写一次存这里，之后直接复制。**
不要在每篇稿子里重新想「怎么引导关注」——那是纯浪费。

## 〇、发布前检查（每次都要做）

> **AI 日报的标准版式以此为准**：`../AI 日报/AI日报_9月21日.md`（改版稿）。
> 骨架 = **发布配置区（标题/摘要/标签/目标搜索词/发布前勾选清单）+ 3 条正文 + 五项固定模块**。
> 后续日报直接复制这个骨架换内容，不要每次重新发明格式。
> 三条底线：**标题实体前置**（见 `标题库.md`）、**只写能搜到的条目**、**总长控制在 1500~1600 字**。

发文前跑一次查重，发完立刻登记。**9 月已经出现过两对同主题重复推送**，
第二次是两个不同标题的同一主题，肉眼看不出来：

```bash
# 发之前：有高风险会返回退出码 1
node CodeKey/07-发布登记/check-publish.mjs "候选标题" \
  --topic=tool-office-tool-plus --date=2026-09-21

# 发之后：往 07-发布登记/发布登记表.csv 补一行（别攒，攒了一定忘）
```

三条硬纪律（2026-09-21 修订）：

1. **一天只「群发」一篇。** 群发位是稀缺资源，两篇群发会互相分流。
   但「只发布」不占群发位，也不受这条限制——日报正是用这种方式跑的。
2. **每条内容发布前都要明确：这次是「群发」还是「发布」。**
   - 工具实测 → **群发**（要推送、要曝光，它决定账号的量级）
   - AI 日报 → **只发布**（不推送、不占次数，进公众号主页与合集，走搜一搜收录）
   **别按错**：工具实测误按成「发布」= 这篇文章白写；日报误按成「群发」= 浪费了当天的群发位。
3. **同一个主题标识永久只用一次。** 详见 `../07-发布登记/说明.md`。

> **只发布的内容，标题必须自带搜索词**，否则等于发给自己看。标题规则见 `标题库.md`。

## 四、互动话术模板

**不要写「欢迎留言讨论」**——这句话没有任何触发力。用**两难选择题**：

```
📌 今日互动：<给足背景>，你觉得 <A> 还是 <B>？说个理由。
```

实例（9 月 19 日日报，可直接参考）：

> 「华为昇腾960提前三个季度发布、英伟达喊话明年翻倍、Meta自研芯片测试中——
> 你觉得三年内国产算力能追平英伟达吗？能 / 不能，说个理由。」

结构 = **给足背景 ＋ 二元对立的两难 ＋ 明确的回答指令**。

## 七、公众号简介（对外的一句话定位）

**主页现在实际显示的是**（2026-09-21 核对截图）：

```
好软件，不私藏。认真折腾，快乐分享！🐵
```

好读，但有个问题：**它不含任何可被搜索的领域词**。搜一搜会把「账号名称、简介、垂直度」算进账号权威度，
所以简介里必须带上你真正在做的领域（软件 / 工具 / Linux / 嵌入式）。

建议改成两层结构——**先给关键词，再给态度**：

```
折腾 Linux 和嵌入式，实测好用的软件与工具。好软件，不私藏 🐵
```

**判断标准**（两条都要过）：
① 读者能不能用这句话向朋友介绍你？② 这句话里有没有一个别人会去搜的词？

## 九、合集：怎么让它显示在公众号主页

**合集创建了 ≠ 主页会显示。** 必须再做一步「账号主页合集配置」，这一步漏掉的人非常多——
主页上就一个合集都看不到（2026-09-21 实测确认）。

### 创建合集

1. **只能在电脑端操作**，手机端不支持。登录公众号后台。
2. 左侧 `内容管理 → 合集` → `创建合集` → 选 `文章合集`。
3. 填写 **合集名称**（直白通俗，让人一眼知道里面讲什么，如「实用软件分享」）、简介、封面。
4. **建议开启「连续阅读」** —— 开启后读者在文末能看到上一篇 / 下一篇。
   对搜索来的新读者尤其值钱：他搜到一篇，本来读完就走了，开了这个才有机会看第二篇。
5. `添加已有内容` → 批量勾选往期文章 → `发布`。

### ★ 关键一步：配置到主页

回到合集页面上方 → `账号主页合集配置` → `编辑` → **勾选要展示的合集** → `确定`。

**只有在这里勾选过的合集才会出现在公众号主页。** 最多可配 10 个，但**建议只挂 3~4 个**，多了显得杂乱。

### 规则备忘

- 一篇文章最多可加入 **5 个** 合集。
- 文章发布后，标题上方会显示「收录于合集『XXX』」，文末也会显示，两处都能点进合集页。
- 合集有利于搜一搜抓取整个账号的内容。

### 本号先建这两个

| 合集名 | 收什么 | 主页位置 |
| --- | --- | --- |
| `实用软件分享` | 工具实测（图吧工具箱、Office Tool Plus、LocalSend、WorkBuddy…） | **放第一位**——主页占了 10.9% 流量，新读者第一屏该看到这个 |
| `AI 日报` | 全部日报 | 第二位，起收纳作用，避免日报占满「全部」 |

> 后续有稳定的技术栏目（Linux 小技巧 / 嵌入式），再建第三个合集。

## 十、搜一搜开关清单（每篇发布前过一遍）

少开一个开关，文章就等于没被收录——这是「发了却搜不到」最常见的原因。

| 项 | 要求 | 位置 |
| --- | --- | --- |
| 允许被搜索 | **打开** | 后台 → 设置 → 隐私设置 |
| 不允许被推荐 | **不要勾** | 发布页 |
| 可见范围 | **全部用户可见**（不要「仅粉丝可见」/ 分组） | 发布页 |
| **原创声明** | **每篇都勾** | 发布页 |
| 摘要 | 填 120 字以内、含核心关键词 1~2 次 | 发布页 |
| 文末标签 | 填 2~3 个相关关键词 | 发布页 |
| 标题 | 核心词放**前半段**，总长 **22~26 字**以内（超了搜索页会截断） | — |

**两条硬事实**（来自搜一搜官方口径）：

1. **内容相同时，搜一搜优先展示「声明原创」的文章。**
   而主页现在显示「**56 篇原创内容**」，已发表却有 **177 篇** —— 只有约三分之一开了原创声明。
   这是一个纯粹白送的损失，从下一篇起每篇都勾。
2. 摘要留空时，系统会**随机截取**正文开头，核心词很容易被截断 → 摘要必须手填。

## 十一、看搜索表现：后台「搜索分析」

后台 → `数据分析`（部分版本叫「统计」）→ **`搜索分析` / `搜索统计`**，可以看：
**TOP 查询词、曝光量、点击量、你自己的排名。**

这是本号唯一能直接看到「读者到底在搜什么」的地方，比单看「阅读来源占比」细得多。

**用法（本号最该做的一件事）**：
筛出**排名在第 5~15 位**的词 —— 这些是「已经能被搜到、但还没排上去」的**潜力词**。
回去给对应的旧文**补标题关键词、补相关段落**，性价比远高于新写一篇。
先做潜力词，再做新词。
