# 固定模块

**每篇文章都要用的文案，写一次存这里，之后直接复制。**
不要在每篇稿子里重新想「怎么引导关注」——那是纯浪费。

## 〇、发布前检查（每次都要做）

发文前跑一次查重，发完立刻登记。**9 月已经出现过两对同主题重复推送**，
第二次是两个不同标题的同一主题，肉眼看不出来：

```bash
# 发之前：有高风险会返回退出码 1
node CodeKey/07-发布登记/check-publish.mjs "候选标题" \
  --topic=tool-office-tool-plus --date=2026-09-21

# 发之后：往 07-发布登记/发布登记表.csv 补一行（别攒，攒了一定忘）
```

三条硬纪律：
1. **一天只发一篇。** 同一天发两篇不会得到两倍曝光，只会互相分流。
2. **确认走的是「群发」不是「发布」。** 只「发布」不会推送给粉丝，几乎没人看得到。
3. **同一个主题标识永久只用一次。** 详见 `../07-发布登记/说明.md`。

## 四、互动话术模板

**不要写「欢迎留言讨论」**——这句话没有任何触发力。用**两难选择题**：

```
📌 今日互动：<给足背景>，你觉得 <A> 还是 <B>？说个理由。
```

实例（9 月 19 日日报，可直接参考）：

> 「华为昇腾960提前三个季度发布、英伟达喊话明年翻倍、Meta自研芯片测试中——
> 你觉得三年内国产算力能追平英伟达吗？能 / 不能，说个理由。」

结构 = **给足背景 ＋ 二元对立的两难 ＋ 明确的回答指令**。

## 五、自动回复配置（后台 → 自动回复）

### 被关注回复

```
🐵 欢迎来到程序小猴！

这里每天 8 点更新 AI 日报，每周更新 2-3 篇嵌入式 / Linux / Python 硬核干货。

三个快捷入口：
· 回复「日报」—— 查看往期 AI 日报合集
· 回复「猴米」—— 领取全套小猴表情包
· 回复「博客」—— 访问我的技术博客（shilong.js.org）

有问题直接留言，我看到都会回。
```

### 关键词回复

| 关键词 | 回复内容 |
| --- | --- |
| `日报` | 往期 AI 日报合集链接 |
| `猴米` / `表情包` | 全套 63 张表情包的领取链接 |
| `博客` | `https://shilong.js.org` |
| `合集` | 全部技术干货分类导航 |

> 关键词回复是**复访钩子**：它让老读者有理由再次打开对话框，
> 而这类主动触达会被计入账号活跃度。

## 六、自定义菜单（后台 → 自定义菜单）

| 位置 | 名称 | 内容 |
| --- | --- | --- |
| 左 | 往期精选 | 跳转 AI 日报合集（图文列表） |
| 中 | 技术干货 | 跳转 `https://shilong.js.org`（博客分类导航） |
| 右 | 关于小猴 | 子菜单：IP 介绍 / 领取表情包 / 商务合作 |

> 中栏指向博客是关键设计：**把博客变成公众号的内容后台**，
> 菜单一点就能拿出 100 多篇文章，不用在公众号里重复造内容。

## 七、公众号简介（对外的一句话定位）

现用：

```
每天 5 分钟看懂 AI 圈，外加程序员的硬核干货。
```

**判断标准**：读者能不能用这句话向朋友介绍你？
说不清就说明定位还没收敛，转发的动机也不会存在。
