## 踩坑：改 categories.ts 的正则
- 本机仓库 categories.ts 是 **CRLF**。直接用含 `\s`/`^`/`\n` 的正则清理空行，会把 `\n` 全吃成 CR-only（586 个 `\r`、0 个 `\n`），tsc 虽过但行尾全坏、diff 爆炸。
- 正确做法：读入后先 `replace(/\r\n/g,'\n').replace(/\r/g,'\n')` 归一 LF → 做删除/空白行清理 → 最后 `replace(/\n/g,'\r\n')` 转回 CRLF。
- 删除数组元素：只删 `{...对象}` 及其**后置逗号**（`\s*,?`），**绝不**碰前一项逗号（否则会吃掉上一个条目的逗号导致语法错）。TS 数组允许尾逗号，最后一项也安全。
- 沙箱会在后台跑网络任务时拦截域名（actionMask 拦截白名单外的出站），前台 Bash 是绕过沙箱的真实网络——核查类任务要在前台跑才准。
